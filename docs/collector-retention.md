# 行业动量保留与增量规则

当前独立及批量入口采集原始数据到 `raw_industry_momentum`，项目同步时计算本地 `industry_momentum`。完整说明见[原始采集与本地计算](raw-pipeline.md)。

每次运行先查询并验证以实际运行当天为基准的180个交易日，再清理原始表中早于边界的所有分类数据；边界当天保留。交易日历缺失、重复、越界或不足180日时不执行清理。显式设置历史结束日期不会把保留窗口移回过去。

首次从配置起始日期和保留边界较晚者开始。后续按已提交日期增量采集，不覆盖已有日快照，不恢复已过期数据。16:00前不采集当日行情。每个日快照的分片在同一事务写入；失败保留已提交日期，重跑续采。

源库清理的键在同步时从本地原始副本删除，再按剩余输入生成结果。旧版MySQL结果表属于迁移保留，不再维护或自动删除；确认迁移无误后可自行归档。网页只查询当前本地结果，不补零、不伪造日期。
