历史独立保存于 `${LOG_DIR}/market-data/commodities/history.sqlite3`。首次初始化幂等导入 `backend/app/data/a00_changjiang.json`，不覆盖已有报价；每个报价日一条，事务更新。当前18日报价到2026-11-02，17日低高区间经正文核验，10月16日保留已核验均价23460及涨跌190，区间仅搜索索引证据，不显示/推算。基线保留originalRangeEvidence用于审计，5个原索引区间已在2026-11-03正文复核。来源固定为CCMN长江现货，不混入有色宝长江、长江综合、SMM或期货。

服务器调度已加入应用生命周期，每天北京时间11:00、18:00各执行一次，包括周末和节假日；非交易日不生成虚构日期。调度随应用服务启动；实际采集是否成功需查看采集状态。首次初始化只等待后续时点；重启补执行初始化之后最近一个未领取时点，不逐个追赶停机期间全部时点。SQLite持久化时点领取及结果，先取得跨进程采集锁再领取，多个worker及手动更新不重叠。失败或硬中断的已领取时点不自动重复，可手动更新或等待下一时点；硬中断在下一调度检查显示中断状态。后台最多5秒检查一次，繁忙时待采集锁释放。日志记录触发方式、时点、结果、读取/失败数量和异常类型，不输出上游正文。管理员也可手动更新当日报价：后台带跨进程文件锁，重复点击不并行；请求有大小和网络超时限制。日常只读取当前报价与日期信息，不扫描历史文章。历史回顾只解析第五节长江市场历史行情，不读第六节预测。已登记来源要求发布日期一致；新发现正文必须明确报价月日，拒绝推算“上一交易日”，缺日期时保留缺口。无登录/付费接口或访问限制绕过；重定向、拒绝访问、格式变化等均计入失败并保留旧数据。基线中首页11月2日快照不作为可反复读取的历史链接。

当前云端客户端访问公开目录时，环境代理路径返回ProxyError，直连返回ConnectError，均未取得HTTP响应；具体连接失败根因尚未确认。浏览工具可打开目录和部分正文，但这不等于生产采集链路验证通过。公开行情页如显示会员限制则跳过，不绕过。已完成离线解析、持久化和调度测试，不声称实际HTTP采集成功。跨年文章日期、上游版式和历史目录覆盖需持续核对。保留整个market-data目录可跨正常部署和重启使用。

## CCI动力煤

入口 `/commodities?instrument=cci`，与A00铝并列标签；三档CCI5500/5000/4500以人民币元/吨折线展示，图例可切换，表格可筛选。只使用来源实际报价日，不生成OHLC、不补零、不沿用前值；来源涨跌缺失保留NULL，绝不从前一条报价推算为官方日涨跌。完整缺失日期不作为报价记录插入；单档缺失在图表对应日期留断点。最新报价日期和最近采集时间分开展示。

来源是 `https://coalindex.com/market` 的普通匿名前端GET查询：`https://coalindex.com/api/market?tab=steamcoal-index&date_from=YYYY-MM-DD&date_to=YYYY-MM-DD&index_name=CCI5500`（另两档分别查询）。`about`声明网络渠道收集整理；它不是已确认的官方授权接口，无稳定性或完整性保证，也未核实再分发许可。页面沿用站点登录权限，明确显示“非官方”；没有绕过登录、会员、付费或限流控制。不要据此声称获有官方授权或将此模块包装成官方数据服务。

基线 `backend/app/data/cci_coal.json` 来自研究线程2026-11-03 01:27:20 UTC的公开查询结果：2026-01-04至11-02，586条、197个实际日期，三档194/195/197条，238条涨跌缺失。相对三个档位日期并集：CCI5500缺03-31、05-29、07-08；CCI5000缺01-21、03-31。没有将另行找到的官方补缺例子混入此来源。该基线只有抽样比对，不代表逐条官方复核；整个日期均缺失也不能判定当天没有官方发布。

数据独立保存于 `${LOG_DIR}/market-data/cci-coal/history.sqlite3`，`cci_quotes`使用报价日期+档位复合主键，来源在本模块固定为coalindex.com，逐条保留`sourceUrl`、`evidence=public_query`、`official=false`。配置、锁和调度账本与A00隔离。每天北京时间21:00首次采集，包括非交易日；A00保持11:00和18:00。服务器内部调度，不创建外部助手任务。跨进程领取、重启防重和失败保留沿用A00机制。CCI定时目标取领取时点的北京时间日期；若重启或线程延迟后该日期已过期，账本记录`skipped`并跳过，不请求历史或把今日结果记到昨日时点。跳过记录使用`skippedAt`，不冒充一次成功采集；当天21:00仍可正常领取。采集结果以运行状态和已保存报价为准。

日常更新仅按单档查询目标当天，不扫描日期范围或补采历史；当天21点首轮未完整取得三档时，至少间隔30分钟有限重试，含首轮最多4轮，成功取得三档即停止，跨北京时间零点停止。每轮保留独立账本时点并沿用同一跨进程锁；重启不重置次数。升级当天已有18点任务仍计入同一日预算，成功则不重复；失败仅在21点及上轮结束30分钟之后再试。旧running任务须先获得原采集锁才标记中断，并从恢复时间重新等待30分钟，不直接抢占21点。恢复、预算判断与领取都在同一锁内。21点前若已有今日旧任务结果，不会制造昨日21点的跳过记录覆盖它；手动更新仍可随时发起。校验`kind/index_type/index_name/unit/date/price/change`，要求响应`total`与行数一致并拒绝1000行截断；全批校验完成后事务保存，失败不清除旧记录。空响应只意味着此免费来源未返回记录，不代表官方无发布。不访问私有持仓源库。2026-11-09云浏览器匿名公开查询能返回11月5/6日三档数据，11月9日三档均为空；直连Python客户端则因开发环境DNS解析失败而未取得HTTP响应。该检查不能证明11月5/6日18:00来源已有数据，也不能代表生产网络、调度或SQLite已核验。详见[本次核验记录](cci-collection-investigation.md)。


### 当日现货与采集状态

A00 每轮先读取公开移动首页，按长江现货 A00 的固定品种链接识别价格行，避免误取广东等其他市场；首页月日须与对应公开日报标题及完整发布日期一致，不用采集日期推算报价日期，也不读取付费正文。11:00 核验当天已发布报价，18:00 核验当天最低、最高和均价并更新同一报价日。两次都取得完整字段时均保存；字段缺失、日期不明或网络失败保留历史。这里是现货报价区间，不是逐笔成交统计。

状态分别记录读取页数、解析页数、新增/改动记录数、最后采集时间、最新报价日期和本时点目标结果。旧首页报价只能表示该公开来源尚无目标日报价；请求失败独立显示，不能当成尚未发布。历史补采成功不替代当天目标成功。已领取时点中断明确记为中断，日期目标取领取时点而非恢复后的当前日期。

解析回归 fixture 根据公开可见文字及链接结构重建，文件中明确标记，并非真实 HTML 下载快照。开发环境直接请求首页返回 ProxyError，尚未验证真实 HTTP HTML 或生产采集；发布后须另外检查实际采集状态与保存结果，不能将 fixture 测试视为生产验证。


### 日常更新与失败日期

页面只保留“更新当日报价”，历史补采按钮/API及通用目录扫描已移除，已有历史基线不删除。正常首页有明确完整报价日期时一次请求；缺年份才读对应公开日期元数据，最多两次。11/18点仍按实际报价日期核验。

每个尝试的目标日期先写入本地 failed_targets；成功报价与删除对应待核验目标在同一 SQLite 事务内提交。失败或进程中断保留目标，重启不会丢失。未发布与网络失败分开记录；这里记录的是未完成核验的日期，不认定该日必有报价或必为休市日，不使用股票交易日历代替现货发布日历。

下一次读到的首页若仍包含此前失败日期，就自动保存并消除该日期缺口。首页已经换日且没有可验证的公开日期查询来源时，旧日期继续显示待核验，不能填前值、用今日价格覆盖或宣称已补回。目前尚未核实可免费定向取得任意失败日完整区间的来源，不能承诺昨天失败一定次日补齐；没有重扫历史文章作为替代。页面最多列20个待核验日期并显示总数；未知非发布日不标为确定缺失报价。


失败日定向尝试：当日首页采集后，从已读取首页的公开链接中最多选一条现铝/铝早评文章，每轮最多尝试一个此前读取失败的日期，不访问受限目录、不猜文章ID、不扫描固定历史URL。只接受第五节历史行情明确写出的报价日期，必须与待补日完全相同；相对日期、预测、缺区间或不匹配均不入库。失败尝试时间持久化，多个缺口轮换处理；源首页仍未发布的日期不按确定漏采自动排入文章回补。已有历史不删除。

这不保证一定回补成功：首页可能没有合适早评，文章可能改版、仅写相对日期、受限或缺区间。此时保留待核验目标及失败原因，下次有界重试，绝不把当日报价当旧日报价。正常无缺口为1–2次HTTP，有失败目标最多额外1次文章请求。原始HTML直连仍未验证，测试文章由已公开核验的段落结构构造，不等于服务器端实采验证。
