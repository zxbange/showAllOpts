# 功能标签状态与国家队采集记录

## 状态灯口径

状态灯区分当前运行状态与最近一次已结束的结果；不会以图表存在、旧的成功时间、任务开始或收到请求作为成功证据。手动和自动运行按实际结束时间共同比较。

- 绿色：最近一次已结束任务成功。
- 红色：失败或部分完成；提示文字区分两者。
- 运行中：有已结束记录时显示运行提示并保留上次结果；还没有完成记录时明确提示该情况。
- 中性：尚无可核验的完成记录、取消、中断或状态接口不可用。
- 已核实的结束记录提示实际类型（采集/数据库同步）、北京时间，以及已知的触发方式。

数据库同步模块包括行业动量、ETF动量、微盘温度计、微盘新高新低、机构持仓及个人持仓。源采集模块不使用其图表缓存同步结果覆盖源采集失败。

微博、雪球在最新动态标签后显示独立灯，避免其中一个平台成功掩盖另一个平台失败。组合调仓单独显示；平台登录等管理标签没有虚构的采集灯。银行与非银行高股息共享同一轮采集结果。

新记录独立于通知开关、推送结果和数据是否发生业务变化。首次升级只采用明确终态且有可信完成时间的旧状态；不能确定的记录保持未知，直到产生新的真实结果。

总览不轮询全站采集结果。功能页通过 `/api/v1/collection-outcomes` 读取状态灯；状态接口和业务数据接口相互独立，图表能读取不代表采集状态可确认。最近 5 次记录及时间定义见[数据更新时间与最近采集记录](data-update-display.md)。

## 国家队动态记录

最近采集记录共同展示手动运行、自动运行和自动重试的每次结果。旧失败保留，新成功按最近结果显示，不再只展示自动时间槽。

调度仍使用原时间槽状态判断是否可以自动重试，展示历史与调度状态分离。相同手动请求的幂等重试不创建重复运行。

旧版本只保存了每个自动时间槽的最后一次状态，因此迁移只保留实际存在的记录，不能恢复此前已被覆盖的尝试。没有旧完成时间时明确显示请求时间，不编造完成时间。服务日志按原轮转策略保留，不因后续成功清除失败日志。
