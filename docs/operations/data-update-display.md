# 数据更新时间与最近采集记录

页面上的三种时间不可互相替代：

- **数据日期/统计日期**：指标对应的交易日、报告期或业务日期。
- **数据更新时间**：页面所展示业务记录携带的实际更新时间。不得使用浏览器当前时间、请求完成时间、缓存刷新时间或最近一次采集成功时间替代。刷新页面不会自行生成该时间；若上游重新发布/写入业务快照，沿用源记录真实写入时间，不保证数值相同时源时间不变。
- **最近采集记录**：任务的真实完成记录，区分手动、自动及数据库同步。一次任务成功并不表示业务统计日期一定推进。

秒级显示采用北京时间；只接受有效的带时区时间戳，或业务已明确按北京时间解释的无时区时间戳。日期字符串、无效时间戳、未接入字段都显示“未提供可确认的秒级数据时间”，不拼接午夜或虚构秒数。仍保留独立的统计日期信息。

页面最近记录只展示最近 5 次；默认仅限制展示和读取数量，不删除既有失败历史，也不改变自动重试规则。另有默认关闭的可恢复归档选项，范围与启用时机见[完成历史保留与恢复](collection-history-retention.md)。没有记录与记录接口暂不可用应分别显示。国家队原有的尝试次数、旧请求时间/中断确认时间说明和错误信息应保留。其他模块使用统一完成结果台账；上线前未持久化的历次任务不能凭最后状态补造。

## 字段来源与未知状态

- 国家队 ETF：当前分组/展示日期窗口的份额和价格更新时间，以及仍展示的最新份额卡片时间；不以仅份额时间忽略价格修正。
- ETF 动量热度：当前池与展示热度记录的真实更新时间最大值；详情取所选历史窗口。
- 市场热度、抱团拥挤度、微盘温度/宽度、两融担保比例：当前最新业务记录的更新时间。
- 高股息与奶牛股：业务快照写入时间；创红比、估值标尺和图表详情页按接口提供的业务数据更新时间。
- 个股机构持仓：已展示报告/股东户数的更新时间，不使用股票目录更新时间；切换股票、标签或加载失败时不借用旧股票时间。
- 行业动量的无时区历史值来源未能确认统一时区，不能猜成北京时间；明确含时区的记录可正常显示。
- A00 铝、CCI 动力煤、个人持仓及博主动态当前未向公共页头传入可用业务更新时间，一律显示未知。页面交易/报价日期、持仓观察时间和帖子发布时间仍有各自意义，不作替代。

通用页脚向 `/api/v1/collection-outcomes/history` 按任务键请求最多 5 条：奶牛股按 3/5/10 年窗口区分，大宗商品按 A00/CCI 区分，银行与非银行共用高股息采集历史。个人持仓历史仅管理员可见。首次上线前未保存的历史不会追溯编造；国家队继续从其采集状态展示原生运行记录。博主的最新动态合并微博及雪球记录后最多 5 条；若任一源读取失败，改为明确提示无法确认完整记录，可注明已显示的是上次读取结果。组合调仓单独显示，监控博主和平台登录管理标签不展示采集历史。
