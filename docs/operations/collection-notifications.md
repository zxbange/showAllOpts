# 采集结果 Telegram 通知

系统配置中各任务的 Telegram 通知开关同时作用于自动和手动采集。自动运行开关只控制定时任务，不影响手动采集通知。个人持仓监控继续沿用原有通知规则。

开启相应模块开关后，自动与手动真正执行的采集均在结束时发送一条同格式结果。内容包括触发方式、完成时间、目标数据日期、结果、已提交的变动记录数、适用时的安全原因，以及可核验的发布指标。没有变动、部分完成、失败、实际取消和中断也通知；关闭模块、休市跳过、忙碌未受理、排队重复请求和仅重试已提交数据的缓存发布，不另发通知。相同任务和运行标识在持久化发件箱内去重，跨进程发送锁避免多个 worker 同时发送；发送前再次检查开关。Telegram 网络异常沿用有限重试，入队不等于送达。

- 国家队动态按页面基金池分组，列出各类别目标交易日的合计份额、上一个正式交易日的合计与增减。两天均须具备同一组完整验证的基金份额；有缺失时标明缺失，不把空值当作零或跳过前一交易日。回补历史、无变动或失败时不拿更新时间替代数据日期。
- 市场热度和抱团拥挤度只从已发布页面快照读取；分别列出百分比、比较日和样本／成交额。创红比和科创红利比显示三条指数和两条比值；估值标尺显示三个指数及可用估值指标；两融显示担保比例变化。
- 高股息通知包含已发布日期、银行与非银行入选数及可验证的股息率等汇总；奶牛股包含三组年限的已发布筛选日与数量。历史比较缺少同口径记录时显示不可比，不生成虚构数据。

A00 铝最低价、最高价、均价分别与该字段之前最近一条有效报价比较；CCI 三档各自比较，不使用其他档位的价格。显示示例 `797(-5)`、`802(+5)`、`797(0)`；无前值为 `797(—)`，当前值无效为 `—`。差值由已发布报价计算，不直接采用来源的涨跌字段。日期严格早于当前报价日期，同日修正不与修正前版本比较，历史回补不与未来报价比较。CCI 部分回补时逐档显示本次最新更新日期，以免把不同日期报价混为同一天。

排查日志可筛选 `Collection notification`：`skipped` 包括通知关闭等规则；`enqueued`、`duplicate`、`sent`、`failed` 表示入队、去重、发送成功或发送失败。日志不输出凭据或通知正文。
