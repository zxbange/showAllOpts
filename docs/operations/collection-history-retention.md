# 采集完成历史保留与恢复

默认 `COLLECTION_HISTORY_RETENTION_ENABLED=false`。此次改动不启用、不执行归档，也不永久清理任何历史。

启用后，每次新完成结果写入成功时，将该记录账本各模块超过最近 5 条的历史移入独立 archive 表；ETF native 完成历史使用相同开关。结果按真实完成时间排序，同时间按写入顺序排序，成功和失败均计入，运行中不算完成。

归档与活动记录删除处在同一 SQLite 事务，先保存完整记录及脱敏详情并核验相等，核验失败则回滚。统一账本 `results_archive` 和 ETF native `run_history_archive` 永久保留，可恢复。归档在同一数据库中，仅能恢复误归档，不是独立灾备；数据库文件整体丢失/损坏时不能保证恢复。归档会持续增长，不节省总存储，不提供自动清空归档功能。永久删除归档须另行明确确认，不包含在此功能中。

不处理股票业务快照、行情、社交消息、自动补采 slots、队列或观察检查点。

从项目根目录，使用项目 Python 环境运行：

```sh
python -m scripts.prune_collection_history
```

默认只读预览，不建库、不写库。经授权后一次可恢复归档：

```sh
python -m scripts.prune_collection_history --apply --confirm-archive-history
```

恢复前关闭 `COLLECTION_HISTORY_RETENTION_ENABLED` 并重启服务，避免恢复后新完成采集再归档。先预览再恢复：

```sh
python -m scripts.prune_collection_history --restore
python -m scripts.prune_collection_history --restore --apply --confirm-archive-history
```

两个数据库各自事务，不是跨库原子操作；若第二库操作失败，检查输出/日志并安全重试。操作幂等，恢复不删除归档。恢复存在主键/记录冲突会回滚而不是覆盖其他结果。

历史错误 `error_details` 仅包含固定错误分类、固定中文说明、白名单阶段、数值 HTTP/MySQL/SQLite 码和严格 ISO 日期。不保存异常原文、SQL、URL、响应正文或凭据。旧记录无详情显示未知，不能从当前错误反填历史。

部署保持默认关闭不会执行清理。后续若明确启用，第一次新完成结果写入时会整理该库既有超限历史；归档失败保留活动记录并告警，可能暂时超过5条，不为满足数量而丢弃未验证记录。用户若要求真正释放存储/不可恢复销毁，本次尚未执行实际永久删除；应先核定候选数量、范围、可恢复副本和执行时机，取得具体确认，不能把归档当成永久删除完成。

## 一次性永久删除（另行逐次确认，不自动执行）

如要求真正删除而不是归档，使用独立永久模式。先只读预览：

```sh
python -m scripts.prune_collection_history --permanent
```

预览包括活动记录、已有归档及对应错误详情的候选数量。保留集合按照活动与归档的去重并集、真实完成时间每模块最近 5 条，保护两处同 key 副本；不能可靠排序的记录保守保留。不会删除运行中记录或调度/补采依赖。

获得本次永久删除的明确确认后，才可执行：

```sh
python -m scripts.prune_collection_history --permanent --apply --confirm-permanent-delete-history
```

该操作不可通过上述恢复命令恢复，归档不作为这些已删记录的备份；没有自动永久模式。每次真实执行都须重新确认，参数不是预先授予的长期许可。两个库分别事务处理。

为阻止旧运行重放后重新出现，只保留最小去重 tombstone（统一账本为 module/run_key，无结果、时间或错误内容）。这些是运行防重元数据，不是展示历史，仍会少量持续增长，不清理业务数据。

SQLite DELETE 通常仅将页标记为可复用，不保证数据库文件立刻缩小；本工具不执行 VACUUM，也不承诺对磁盘残留字节进行安全擦除。永久删除会移除可查询/可恢复的业务历史内容，但不等于立即释放文件大小。

ETF 原生永久清理的保守排序：未知状态或时间无法由 SQLite `julianday` 解析的记录额外保留，不计入最近 5 条可排序终态。旧记录缺少完成时间但请求时间有效时，沿用页面的旧记录排序口径，排在具有完成时间的记录之后；不会把请求时间伪装成完成时间。调度与手动请求账本及一次性迁移标记保持不变，避免重试、重复取消或启动迁移重新生成已清理历史。
