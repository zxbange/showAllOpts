# 页面内短线胜率验证

入口：短线选股 → 短线胜率验证。只开放补票龙、红悬停、蓄力龙、超跌后止跌反弹，可单选或多选。起始日默认2024-01-01，两个截止日留空时使用已采集最新收盘交易日。先选择策略/日期，再开始验证；刷新页面并重新解锁后会显示最近30个任务。暂停后点击“从断点重试”。若源数据已修复，点击“准备重新读取数据”，再开始验证，会建立新任务并保留旧结果；同参数正在执行的任务仍会合并。

统一原四策略沪深股票池与基础过滤、后复权OHLC和原始成交量；原90交易日形态窗口、内部60/65行截取和EMA初始化不变。指标是T收盘相对T+1/2/3收盘的严格正收益，持平计入有效分母；各期限独立剔除停牌和缺行情，末尾未到观察日单列。没有有效样本显示空值，有效样本不足30提示不稳定。这不是可成交收益或逐笔实盘回测。红悬停价格取整和统一股票池可能改变生产信号。

## 数据和部署依赖

仅SELECT现有 `ultra_research_calendar`、`ultra_research_universe`、`ultra_research_bar`；不建源库表、不触发采集或同步。连接沿用服务Settings/APP_ENV_FILE；不读取命令行脚本私有JSON。运行依赖新增numpy、pandas，已纳入锁定依赖。股票池清单上限20000、单股行数上限4000、日期范围上限10年；需开始日前160个交易日预热数据。

任务、冻结输入、逐股信号和聚合行持久化在 `Settings.log_path/short-validation/jobs.sqlite3`。该目录与既有服务器log持久目录一致，不属于前端构建或发布清理目录；容器仍须挂载现有log持久卷。备份时使用SQLite在线备份或停服务后复制整个目录，不应删除数据库。验证管理现在独立要求管理员密钥及HTTPS，详见下文。

每个进程启动轮询线程，OS文件锁覆盖整个工作单元，SQLite事务将输入/结果和断点一并提交。服务重启可重新领取未完成单元；取消时不提交当前计算；已提交股票不会重算或重复计数。请求不执行统计。查询连接/读取超时分别8/20秒，读取逐股有界；没有定时虚增进度，每20个实际处理信号日更新活动。源库缺表、缺列、缺预热、无基础样本均失败而非当作0。

先逐股冻结输入，再开始计算；每股两个表在同一源库事务读取。已保存输入不会在重试时重新查询。冻结过程中源库若同时修订不同股票，并不保证跨全部股票的同一数据库时刻；研究时应使用已完成采集的日期。冻结完成后，一次计算与断点重试使用同一份输入。结果聚合由SQLite完成（含中位数），不会在内存拼接所有股票明细。

旧七策略/原四策略CLI入口保留，内部实现迁入 `backend/app/services/short_statistics.py`；原参数、CSV和历史结果不删除。CLI需完整项目目录，相对配置路径仍以原 `脚本/本地统计` 目录为基准。网页新任务共用该引擎但只提供上述四种，不会计算未选择策略。

## 验证和已知范围

离线合成数据覆盖结果口径、浮点无损恢复、失败恢复、进程实例重启、互斥、重复点击、暂停时不提交、单/多策略一致、缺行情和空信号。浏览器测试覆盖选择、失败重试、刷新后任务恢复与空值展示。未连接生产数据库，不能据此确认真实库索引、容量或实际长跑性能；旧脚本热点是代码风险观察，不是已确认现场根因。

## 手动数据库配置与管理员权限

验证管理现已独立鉴权，使用 `VALIDATION_ADMIN_KEY`（至少32字符随机管理密钥）。现有普通HTTP地址不能提交管理密钥或连接凭证；部署者需先提供HTTPS入口，并只信任真实反向代理传来的协议头，不要把任意来源的 `X-Forwarded-Proto` 当作可信认证。API自身拒绝非HTTPS管理请求。页面管理密钥只保存在当前页面内存，刷新或锁定后需重新输入；不会写入localStorage/sessionStorage。原短线选股查看不受此管理员解锁影响。

部署者需要在服务器私有环境或 `APP_ENV_FILE` 指向的受限配置文件中设置以下三项，再重启服务。本次开发没有生成或安装生产密钥、凭证，也没有更改生产访问配置：

- `VALIDATION_ADMIN_KEY`：独立的高强度随机管理密钥，至少32字符，不与加密密钥共用。通过安全渠道交给授权管理员，不在聊天、URL或日志中传递。
- `VALIDATION_ENCRYPTION_KEY`：由部署者在可信环境生成的Fernet密钥（URL-safe base64编码的32字节密钥）。通过环境/私有配置注入，**不存入管理SQLite**。保护配置文件权限并单独备份密钥。程序不会自动生成密钥或降级明文保存。首次写入建立加密校验哨兵，换成另一密钥会拒绝读写；本版本不提供密钥轮换迁移工具，不能直接替换密钥。丢失原密钥将无法恢复原连接配置。
- `VALIDATION_ALLOWED_TARGETS`：JSON字符串数组，逐个列明部署者批准的、小写的精确 `host:port`，例如 `["research-db.example:3306"]`（仅格式示例，不是实际目标）。不要批准不受信任的域名或使用通配符。服务默认数据库若要用于验证，也须加入此列表。只影响验证模块，不修改其他模块的数据库配置。

保存位置仍为 `LOG_DIR/short-validation/jobs.sqlite3`，其中 `validation_sources` 保存全部连接字段的认证加密密文、ID/版本/时间；密钥来自上述独立环境配置。此库是服务器管理存储，不是用户选择的统计源库。源库只执行SELECT，连接测试检查三张研究表和必要字段，不创建表或触发采集。

解锁后可选择“服务默认数据库”或保存的手动配置，展开新增/编辑表单，填写名称、地址、端口、库名、用户名、密码、TLS及可选CA证书。默认TLS为加密并校验证书/身份，也可明确选择仅加密或可信网络下禁用TLS。`PyMySQL>=1.2.3`保证要求TLS时在无TLS服务上认证前拒绝降级。密码不会回显；编辑时空白表示保留原密码。测试连接与保存失败时保留本次页面内存输入供修正；成功保存、清空或锁定后清除密码。

每次编辑保存创建不可变新版本；新任务绑定选中的ID及版本。服务默认配置也会加密冻结为版本，连接遵循现有PyMySQL默认的优先TLS模式（非强制校验证书）；需要强制校验证书请创建手动配置。其他模块的连接设置不改变。修改密码、库名或服务器配置不会把旧任务切换到新源库。旧版本失效而输入尚未冻结完成时，任务报错，需要用新配置新建任务。冻结完成后的继续只读已保存输入，即使加密密钥暂缺也不重新连接源库。

网络连接仅允许精确目标，DNS解析最多等待5秒并最多占用4个后台解析槽位，解析后固定IP建socket，TLS仍校验原主机名。云元数据常见地址、链路本地、未指定、多播、保留范围即使误加到允许列表也拒绝。内网目标必须由部署者明确允许；该限制不是通用网络防火墙，仍应保留服务器出口限制和只读数据库账户。连接测试失败只返回脱敏提示。

## 暂停与终态取消

“暂停任务”保留断点，可“从断点重试”。“取消任务（不可继续）”是终态操作，保留历史任务、已提交输入和结果用于审计，不删除已有完成结果。运行中取消先显示“正在取消”，并记录请求时间；不会使用需要额外权限的KILL QUERY。已经发出的查询可能等到返回或驱动超时，后台在查询/计算边界检查状态和执行代次，丢弃未提交工作。获得全局工作锁、确认无在途工作后才标记“已取消”并记录确认时间。

重复取消幂等；取消中和已取消不能重试，需准备新任务再开始。服务重启会完成取消收尾，不会复活已取消任务；暂停/失败仍需手动继续，原等待/运行任务自动恢复。算法升级前未绑定配置版本的旧任务若尚未冻结完整输入，会明确要求新建，避免把重启后的服务连接混入旧任务。
