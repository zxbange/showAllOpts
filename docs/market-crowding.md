# 抱团拥挤度：采集与展示

本模块已切换为聚宽原始采集、项目同步时本地计算，结果保存到本地SQLite供网页查询。独立及批量文件名不变，顶部使用 `DB_CONFIG` 和按策略分组的 `STRATEGY_CONFIG`。运行、首次迁移、原始表、增量和保留规则以[原始采集与本地计算](raw-pipeline.md)为准；下文说明计算口径。

## 计算口径

每个交易日用 `get_all_securities(types=['stock'], date=当天)` 获取当时的股票列表，再用 `get_price` 获取同一天的日成交额 `money`。

- 股票总数为 N，取 K = max(floor(N × 0.05), 1)。
- 按当日成交额降序，选取前 K 只股票。
- 原始占比 = 前 K 只股票成交额合计 / 全部股票成交额合计。
- `TOP_PCT = 0.05` 保持不变。股票范围沿用原程序返回的列表，不另行添加上市期限、ST、停牌或交易所过滤；零成交额股票计入 N。
- 入库比例范围为 0～1，页面乘以 100 显示百分比。区间变化以「百分点」显示，统计卡片全部使用原始占比。
- 少于 100 只股票、缺失/负数/非有限成交额、股票列表不完整、重复股票、日期不一致、总成交额为零时停止，不写入失真的数值。

原程序对异常和空数据直接跳过。新版本会停止并提示失败日期；已提交的日期保留，修复后重跑从最后已提交日期继续。聚宽接口权限、请求限额或行情尚未就绪也可能使采集停止。

## 网页展示与接口

入口：`/market-crowding`。展示最新占比、最新入库日、前 K / N 只股票、成交额、区间最高/最低/均值及百分点变化。曲线支持 30 / 90 / 180 / 365 个自然日和全部历史，默认一年，区间终点为最新入库日；底部滑块可缩放。

`GET /api/v1/market-crowding/history?days=365`

- `days` 支持 0、30、90、180、365，0 表示全部；固定读取 TOP_PCT=0.05。
- 可传 `end_date=YYYY-MM-DD` 查看截至历史日期的数据，拒绝未来日期。
- 一次 SELECT 读取从 2020 年至查询结束日的日记录，同时生成最新值、统计及曲线，减少公网数据库往返。
- 返回原始比例 `ratio` 和平滑比例 `smoothed_ratio`，两者均为 0～1；`change_pp` 已是百分点。
- 空表返回 200 和空数据；表尚未创建、连接失败或权限不足返回统一 503，界面支持重试；非法参数返回 422。
- 数据库没有独立交易日历，网页仅展示实际存储日期，不把周末或缺失日期填零，也无法仅凭该表区分节假日与采集缺口。默认增量模式不会自动修复早于最新日期的历史缺口；需要补录时，明确传入起止日期和 `incremental=False`，将重算并替换指定区间的所有交易日。

平滑线采用原程序的备用算法 `ewm(span=10, adjust=True)`，可取消勾选。每次使用完整已存历史计算，再裁剪显示范围，因此切换范围不会改变同一天的平滑值。平滑仅用于展示，不写入数据库。

原程序优先使用 Savitzky–Golay 平滑，其中心窗口及拐点识别依赖后续日期，新增数据可能改变历史局部结果。本模块统一使用只依赖当前及过去数据的 EMA 10，不复制该平滑算法及拐点箭头。原始指标口径保持一致，原始线、最新值标记及区间均值参考线同时可见。
