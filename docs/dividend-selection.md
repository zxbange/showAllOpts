# 高股息选股

本模块已切换为聚宽原始采集、项目同步时本地计算，结果保存到本地SQLite供网页查询。独立及批量文件名不变，顶部使用 `DB_CONFIG` 和按策略分组的 `STRATEGY_CONFIG`。运行、首次迁移、原始表、增量和保留规则以[原始采集与本地计算](raw-pipeline.md)为准；下文说明计算口径。

## 已确认的两种方法

| 方法 | 筛选和排序 |
| --- | --- |
| 纯高股息 `classic` | 近三年累计分红比例前 10%，再要求 0.1 < PEG < 2、营业总收入同比 > 3%、净利润同比 > 8%、扣非净资产收益率 > 4.5%；最后按三年累计比例降序取前 25 |
| 高股息低估值 `value` | 近一年股息率 > 4%，且 0 < PE < 8；按近一年股息率降序取前 25，不附加第一组的盈利增长条件 |

所有边界均为严格大于/小于；PEG = PE / 净利润同比的百分数数值，例如 15 / 20 = 0.75。使用 `indicator.inc_net_profit_year_on_year`，不是归母净利润增长率字段。三年累计分红比例没有年化；不是 V2 的月度、10 只或更高增长门槛。

两组共用可选股票池：使用历史股票列表，剔除代码以 4、8 开头的股票，以及 ST / 名称含 ST、*、退的股票。**允许 68 开头的科创板股票入选，不剔除停牌、涨停或跌停股票**，不另加上市天数限制。行情只读取收盘价用于展示，停牌时保留数据源填充的收盘价；收盘价缺失或无效仍中止采集并保留旧结果。该程序只做研究选股，没有真实持仓，因此没有持仓豁免，不执行原策略的买卖、资金修改或涨停打开卖出规则。

本次股票池调整后的规则版本为 `dividend_top25_v2`。更新独立或批量采集脚本后需重新运行，两组最新结果会按新股票池重新计算并一起替换，无需修改数据库表结构。

分红数据来自 `finance.STK_XR_XD`，分两种日期口径：

- 第一组沿用原程序：按 `a_registration_date` 股权登记日统计截至选股日最近 1095 天的累计金额。排名分母为可选股票池内有该区间分红记录的股票数量，前 10% 向下取整；不是先做盈利筛选再取前 10%。
- 第二组：按 `a_xr_date` 除息日统计 `(选股日－365天, 选股日]` 的现金分红，左开右闭，避免把恰好一年前的分红重复纳入一年窗口；尚未除息的方案不计入一年股息率。使用除息日判断已实施分红与[聚宽技术支持说明](https://www.joinquant.com/community/post/detailMobile?postId=21247)一致。
- `bonus_amount_rmb` 按原程序的万元口径换算，总市值 `market_cap` 单位为亿元。百分数 = 分红金额 / 100 / 总市值；例如 50,000 万元 / 100 / 100 亿元 = 5%。数据库比例保存为 `5`，网页显示 `5%`。
- 同比例按代码升序稳定排序；筛选和排序使用未舍入值，写入时用 Decimal 统一到 6 位小数，避免浮点尾数截断。页面显示两位小数，紧邻门槛的值可能四舍五入显示为 4.00%，但实际大于 4%。

所有估值和财务查询显式使用所选交易日；股票各自最新已披露报告期可能不同，页面展示报告期和公告日期。相对原来 09:31 调仓所用的前一交易日数据，本程序生成的是所选完整交易日的研究快照。现有源数据后续修订会在重跑时反映，不承诺逐时点还原过去的实时交易结果。
