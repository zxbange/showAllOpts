# ETF 分类去重研究脚本

文件：`collectors/ETF分类去重_研究版.py`。完整复制到聚宽研究环境的单元格运行即可，不依赖本地文件、数据库配置或其他采集脚本，不执行交易，也不加入每日数据库采集任务。

## 选取口径

- 范围为聚宽 `get_all_securities(types=['etf'])` 提供的 ETF，不含 ETF 联接基金；额外纳入能确认国内股票/混合投资类型的上市 LOF。货币 ETF 不在此次七类范围内。
- 使用已经核对字段的 `finance.FUND_INVEST_TARGET`：`code`、`pub_date`、`start_date`、`end_date`、`traced_index_code`、`traced_index_name`。只使用截止日期已发布且生效、尚未结束的关系；冲突进入待核对清单。黄金现货、豆粕期货、有色金属期货可采用脚本内明示的商品方向补充，不再完全依赖股票指数映射表。黄金股仍不归入黄金现货。
- 默认按跟踪指数代码去重。同一个指数只保留一只；不同半导体指数、不同红利指数不会自动合并。商品使用黄金现货、豆粕期货、有色金属期货等方向分组，并明确保留源标的和分类依据。没有指数代码时按完整标的名称分组。可用 `OVERRIDES` 的 `group` 人工合并方向。
- 规模 = `FUND_SHARE_DAILY.shares`（份）× `get_extras('unit_net_value')`（元/份）。不使用成交额、累计净值、复权价格或份额数量替代净资产规模。
- 每组在最近 15 个交易日中找到所有候选都有份额及净值的最新共同日期；最多允许落后截止日 3 个交易日。缺少共同日期或日期过旧时整组暂不选，避免漏掉大规模竞争者。不同组可能使用不同日期，输出保留规模日期。
- 规模必须严格大于 **30 亿元**（等于也不通过），适用于全部类别及白名单基金；`MIN_SIZE_YI` 可以调整。最大候选未过门槛则整组排除，候选明细仍保留其规模。
- 跨境只允许原 `ETF动量策略.py` 中的七只：`513100.XSHG`、`159509.XSHE`、`513030.XSHG`、`513520.XSHG`、`513690.XSHG`、`513130.XSHG`、`159550.XSHE`。先限制候选，再进行去重和规模筛选。
- 债券只允许城投债 ETF `511220.XSHG`，同样必须通过规模门槛。
- 规模相同时按基金代码升序取一只。输出按七类ETF及国内LOF顺序、规模降序排列。

## 国内 LOF

通过 `get_all_securities(types=['lof'])` 获取上市名单，使用 `FUND_MAIN_INFO` 的基金名称、资产类型、投资风格确认国内股票型/混合型范围。跨境、债券LOF排除；缺失、冲突或未知类型列入审计清单。南方原油属于跨境LOF，不再作为例外。

LOF 没有可靠统一的跟踪标的映射，当前按基金代码独立保留，不把主动投资组合强行按名称去重。每只都必须严格大于30亿元。该规则与ETF按指数取最大产品不同。

规模使用 `FUND_FIN_INDICATOR` 六位基金代码的 `total_tna`（元），是对应份额类别净资产，不代表A/C等全部类别合计。按截止日已披露的最新报告期、最新披露日期取值；报告期最多落后180自然日。缺失、无效、冲突或过旧均不入选，不退回场内份额计算。输出保留规模日期及披露日期。

## 配置与分类

`AS_OF_DATE=None` 默认北京时间昨天及之前最后一个交易日；也可以填写已经结束的日期。数据可能延迟，设置过近日期不保证所有产品都有结果。

七类为宽基、行业、主题、策略/风格、跨境、商品、债券。分类基于指数名称关键词，是研究分类，不是官方分类。交叉方向按脚本中规则优先级归类；例如恒生科技归跨境，红利低波归策略。商品黄金与黄金股不混用，不能识别的方向列为待核对。请审阅 `classification_reason`，按需要在 `OVERRIDES` 修正。

```python
OVERRIDES = {
    '510300.XSHG': {'category': '宽基ETF'},
    # 基金代码优先于指数代码。以下只是自定义方式示意：
    # '已核对的指数代码': {'category': '行业ETF', 'group': '半导体方向'},
}
```

这不是“每个大类只取一只”，而是“每个大类中每个不同跟踪标的取一只”。名称别名、缺失指数代码、平台产品覆盖及延迟都可能影响结果，脚本不会将部分覆盖冒充全市场完整结果。历史日期查询也不能替代完整的历史时点数据库：基金名称及数据修订未必具有历史版本。

## 输出

- `selected_df`：去重结果（代码、名称、分类、标的、规模亿元、规模日期、同组产品数）。
- `candidate_df`：已完成同日比较的各组全部候选及组内规模排名。
- `audit_df`：未识别、白名单排除、规模门槛排除、冲突和缺少规模数据等问题。控制台还单独输出黄金 518880、南方原油 501018、豆粕 159985、有色期货 159980 的状态和排除原因。
- `ETF_POOL`：入选代码列表，可复制给轮动策略。
- 默认导出三个带日期的 CSV 文件，可在聚宽研究文件区下载；设置 `EXPORT_CSV=False` 可关闭。

不需要配置数据库密码。API 权限或网络异常会明确报错，不会将失败当成无数据继续输出结论。本地测试覆盖去重和排名逻辑；全市场数据覆盖需在聚宽账户中实际运行验证。
