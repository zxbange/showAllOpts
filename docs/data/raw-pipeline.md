# 计算入库与历史兼容

聚宽策略采用：研究环境采集、筛选并计算 → MySQL 保存结果 → 项目同步到本地 SQLite → 页面展示。公开接口采集由项目服务完成，来源和口径按模块记录。

- 批量与独立聚宽脚本仅共用 `mysql_connector.py`；修改公共规则须同步内嵌版本。
- 网页同步只搬运已计算结果，不重新计算选股。原始采集方案留下的 `raw_*` 等表不再使用，但不自动删除。
- 采集以日期或披露事务提交，失败保留已提交部分；同步仅发布校验成功的快照，失败继续显示上一份数据。
- 数据保留、补采和修订不能一概按最新日期处理，遵守各模块规则；不为升级清库或清空缓存。

当前入口见[批量采集](collector-batch.md)，增量与历史修复见[同步策略](../operations/cache-sync-strategies.md)，数据保留见[保留策略](collector-retention.md)。
