# 两融平均维持担保比例

入口：“市场情绪 → 两融担保比例”，路径 `/margin-guarantee`。展示每日比例、变化百分点、距240%参考线、近六年历史分位及最高最低值。

## 来源与口径

直接请求东方财富 JSON 接口 `https://datacenter-web.eastmoney.com/api/data/v1/get`，报表为 `RPTA_WEB_MARGIN_DAILYTRADE`，读取 `STATISTICS_DATE` 和 `AVG_GUARANTEE_RATIO`。无需 Token，不调用聚宽或 MySQL，不根据担保物总价值和融资余额反推比例。

日期使用统计日期，数值单位已是百分比：`262.6319` 表示 `262.6319%`，不乘100。空值不填零、不前向填充，保留待补；日期越界、重复、分页不完整、非数值等情况报错并保留已有数据。该接口属于网站数据服务，字段与访问规则可能变化。

240%和150%仅为观察参考线，不代表统一监管要求。历史分位为有效样本中严格低于当前值的数量除以有效样本总数；同值不计入低于数量。统计基于全部已采集的近六年记录，不随图表缩放变化。

## 自动更新与补采

- 每天北京时间 **08:00** 检查一次，调度间隔约30秒，不依赖服务器本地时区。只保存实际披露的数据，不承诺当天已有数据；页面显示实际统计日期。
- 默认开启，`MARGIN_WORKER_ENABLED=false` 仅关闭定时采集，仍可手动更新。与其他模块数据库同步独立。
- 启动仅注册定时任务，不立即采集，不补跑停机错过的时段；首次可手动点击“采集历史数据”。
- 首次使用新接口（含旧中证版本升级）批量查询近六年，每页最多500条。完整校验分页后保存待补清单，复用已返回数值，不为每一天再发请求。
- 后续查询最新已知统计日前七天起的区间；若存在更早的接口待补日期，则延伸至最早待补日期，批量续传而非逐日请求。已有有效记录、原来源和更新时间保持不变，不重复写入。
- 未保存日期逐日提交，取消或中断不会丢失已提交记录。未披露比例的旧日期保留待补，超过近期窗口仍可按日期重试。连续三份日数据失败时结束本轮，下次继续。
- 按运行日期向前六个自然年保留历史，成功读取接口后清理过期数据。多个进程通过文件锁和任务日期避免重复执行。

## 升级兼容

保留原中证数据，不清空缓存。旧清单中尚未解决且未被新接口覆盖的日报仍使用原中证解析器续传。旧目录的已核验标题日期更正凭据继续保留，不将2023-09-28的观测错误写到2023-10-06。新接口正常采集不再扫描中证网页或逐份下载Excel。

## 图表

与国家队动态使用一致的折线及底部缩放滑块。支持拖动两端调整区间、拖动选区平移、Ctrl＋滚轮缩放、触屏双指缩放，以及近1月、近3月、近半年、近1年、全部快捷范围。点击“全部”恢复完整区间。刷新数据保留当前缩放，240%和150%参考线及标签保持可见。采集更新栏位于图表下方，旧中证日期更正说明不再显示。

## 存储、部署与诊断

本地文件为 `LOG_DIR/market-data/margin-guarantee/history.sqlite3`：`points` 保存有效比例，`reports` 保存待补日期及来源，`state` 保存任务状态，`report_resolutions` 保存旧中证日期更正凭据。备份和迁移时保留整个目录。

部署后重启后端并更新前端。服务器需要通过HTTPS访问 `datacenter-web.eastmoney.com`；旧待补日报还可能访问 `www.csdata.cn`。保持证书验证开启。

API：`GET /api/v1/margin-guarantee/history`、`GET /api/v1/margin-guarantee/status`、`POST /api/v1/margin-guarantee/refresh`、`POST /api/v1/margin-guarantee/cancel`。刷新返回202表示任务已接收，最终结果看状态。

失败显示经过筛选的原因、错误码和日期；未知异常不暴露响应正文、请求头或异常原文。重新采集清空旧错误提示，保留历史和待补日期。
