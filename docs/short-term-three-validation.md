# 短线三策略：聚宽研究版

已有数据库、只需本地计算时请使用[七策略统一入口](seven-strategy-statistics.md)。本页研究版会通过聚宽查询历史数据，不是本地数据库版。

上传 `脚本/本地统计/短线三策略胜率验证_研究版.py` 到聚宽研究 Notebook，执行：

```python
%run 短线三策略胜率验证_研究版.py
```

仓库中与四策略脚本放在同一目录，但此脚本仍需在聚宽研究环境运行。也可将完整脚本粘贴到单元格。不需要数据库配置、其他策略文件或网页改动；不运行生产采集，不下单。

默认 `START_DATE='2024-01-01'`，元旦不交易，实际从交易日历中的 2024-01-02 开始。`END_DATE=None`、`AS_OF_DATE=None` 使用北京时间16:00前的上一日/16:00后的当日，再落到聚宽交易日历的最后交易日。原本地统计依赖数据库最新已采集日期，此脚本直接请求聚宽；接口尚未提供的数据会报错或计为缺少行情，不声称已采全。

## 口径对照

| 项目 | 本验证脚本 |
| --- | --- |
| 选股 | 红悬停龙（页面红悬停）、蓄力龙、补票龙，完全保留原生产条件 |
| 历史池 | 每日历史上市股票、当日非ST、总市值至少30亿元；含当时上市而后来退市股票 |
| 信号数据 | 当日及之前前复权日线，90交易日预热；补票龙内部60条、蓄力龙65条 |
| 收盘统计 | 原四策略 `forward_outcomes`、`summary_table`、`window_summary` 原样复用 |
| 基准和期限 | 信号日为0，以当日后复权收盘为基准，观察市场第1、2、3交易日收盘 |
| 收益 | `(观察日后复权收盘/信号日后复权收盘-1)*100`；两个端点同次请求 |
| 胜率 | 严格正收益计胜，持平入分母不计胜；各期限独立有效分母 |
| 排除 | 观察日停牌、行情缺失、待观察分别列示，不进有效分母；不顺延交易日 |
| 三日窗口 | 只使用三个观察日都有效的样本，计算任一收盘上涨率及最好/最差收盘收益均值 |
| 重复信号 | 同策略同日同股仅一次；不同日期和跨策略独立计数，相关样本不等于独立交易 |
| 成交与费用 | 与四策略一样是收盘表现，未模拟买入成交、涨跌停限制、手续费或滑点 |

不套用四策略特有的上市满一年、成交额、板块等过滤，也不额外排除原生产规则允许的信号日停牌；否则会改变三个策略的现有股票池。原四策略的信号池自身有额外限制，因此三策略和四策略的样本构成不同，只有后续统计口径相同。

这不是旧 `短线选股胜率_研究版.py`（第2/4/10日、含停牌估值）更名，旧脚本和断点均保留，互不混用。

## 输出及续跑

`research_result.summary` / `winrate_df`：3策略×3期限胜率、样本数、上涨/持平/下跌、平均/中位/最差/最好收益及排除数量。

`research_result.windows` / `window_df`：三日窗口。`research_result.details` / `detail_df`：每个信号及其三个期限的价格、日期、状态、收益。`research_result.monthly`：月度统计。`research_result.daily_counts`：每日历史池、扫描及入选数量。

结果自动保存于 Notebook 工作目录 `短线三策略验证结果/<运行时间>/`：`收盘胜率汇总.csv`、`三日窗口汇总.csv`、`策略信号明细.csv`、`按月收盘胜率.csv`、`数据覆盖.csv`、`运行参数.json`。CSV使用UTF-8 BOM；数据覆盖是每日扫描计数，不是原四策略数据库逐股覆盖表。

首次回放2024年以来全市场可能耗时较长，界面显示逐日进度和当前采集阶段。`short_term_three_validation_cache/short_three_close_v1/` 按日保存名单与按批完成的观察结果；中断后重跑会复用名单，补缺失或新增成熟观察期。零入选日也保存。缩短观察截止日期会重新计算较短窗口，不泄漏较晚缓存。有效缓存不自动修订，源数据更新后需要换 `CACHE_DIR` 或 `use_cache=False` 完整重采；勿同时写同一目录。

可先更改顶部日期做小范围试跑；加载脚本后可调用：

```python
research_result = run(start_date='2024-01-01', end_date='2024-01-31',
                      as_of_date='2024-02-08', cache_dir='short_three_trial_cache')
```

支持Python 3.6语法，不用现代pandas专属 `to_numpy()`。本地测试用模拟接口，未运行聚宽真实历史行情，未提供或推断真实胜率。
