# 博主配图通知

微博和雪球新采集帖子会保存可识别的配图 URL，Telegram 先发送原有文字与原文链接，再按顺序逐张发送图片。飞书仍使用原文本通知。原有无评语微博转发过滤不变。旧记录没有保存图片 URL，不回补、不重发历史通知。Telegram Bot Token 和 Chat ID 在「系统配置 → 接口凭证」统一保存，是否发送博主通知由「社交通知」中的 Telegram 开关独立控制。

- 最多 18 张；单图最多 10 MiB；支持 JPEG、PNG、WebP。动图/视频、其他域名、受权限或防盗链限制的图片仍需查看原文。
- 下载仅接受平台图片 CDN HTTPS 域名，检查并固定公网解析地址，验证 TLS，不跟随重定向，不携带 Cookie/登录凭据，也不读取本机文件。限制响应大小、类型、文件签名，使用 15 秒连接/无活动超时及 30 秒响应体读取期限；DNS 解析依赖系统超时，非严格整次请求 30 秒上限。
- 正文成功后独立处理图片，图片失败不会重发正文或阻断后续帖子。渠道开关、博主暂停/删除、原队列隔离继续生效。
- Telegram 未提供发送幂等键。每张图在尝试前持久化进度，网络超时或进程中断后不盲目重发，避免重复；代价是结果不明时可能漏图，日志及帖子 delivery.image_warning 会记录。发送锁忙或既有限流等待等尚未尝试的状态保留待发进度；下载完成后再次检查博主状态、监控窗口和 Telegram 接收目标，避免向下载期间已变更的目标发送。成功文本通知的 sent 不代表全部图片一定送达。
- 当前功能是逐图发送，不是 Telegram 相册。未做生产账号真实送达验证。
