# 估值标尺

入口：市场情绪 → 估值标尺，路由 `/valuation-ruler`。左轴沪深300原始指数收盘点位，右轴当日成分股正PE-TTM等权算术平均；P20/P80使用2010年以来全部已成功采集的日均值，不随图表可视区缩放重算。分位数使用排序后的线性插值，不是PE数值20/80，也不是当前值的20%/80%。页面显示实际覆盖起止与缺口；“已采集全部”不表示2010年以来从未缺日。

## 每日计算合同

- 每个交易日使用该日300个唯一成分，不能用当前或月频成分倒推过去。
- PE取明确的TTM字段。仅有效正数参与等权平均，负数单独统计。缺失PE保留为NULL，单列统计，不参与均值、不计为亏损；完整300只成分全部保存。零、无穷值、非法数值、缺码、多码或重复码阻断当日；没有正PE样本时不生成均值。
- 原始值须满足存储精度，拒绝静默舍入。日均值和PE总和按固定Decimal精度生成。
- 高正PE不截尾、不去极值，因此极高PE可能影响等权均值。成分数、正PE数、负PE数、缺失PE数、成员哈希、来源和日期均保留。页面及曲线提示显示正PE样本和缺失数量，避免把样本不全误认为300只都有有效PE。

## 历史与日常来源

历史使用 `collectors/估值标尺历史补采_聚宽研究版.py`：`get_index_stocks('000300.XSHG', date=D)`、同日 `valuation.pe_ratio`（PE-TTM）及原始指数收盘。完整300成员与日历写入可配置MySQL，页面“同步聚宽历史”只读验证后原子追加到SQLite。详见 [聚宽历史说明](joinquant-market-valuation-history.md)。聚宽当前可见历史可能已修订，不声称原始未修订PIT。

日常成分使用中证官方 `https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/file/autofile/cons/000300cons.xls`，必须核验文件内部日期=目标日。该URL只提供当前快照，不具备已验证的任意历史日查询。每日完整文件缓存后可用于该日重试；缺失过往快照的日期须用聚宽补齐，不能拿最新成员补历史。

日常估值来自东方财富 `https://datacenter-web.eastmoney.com/api/data/v1/get` 的 `RPT_VALUEANALYSIS_DET.PE_TTM`，按目标日期完整分页，再与官方300成员逐只左连接。泛称PE或指数整体PE不能替代。指数原始日收盘来自东方财富 `push2his.eastmoney.com/api/qt/stock/kline/get` 的 `secid=1.000300,klt=101,fqt=0`。日期、代码、分页计数、唯一性与覆盖都需验证。公开接口没有稳定性保证，拒绝、超时、结构变化保留旧数据并报错。

当前没有证明20点官方成分文件一定已更新到当天；内部日期仍为前一交易日时保留待补，不伪造当天成功。也没有完成真实聚宽与东方财富的全历史等价验证。

## 调度、手动补采及冲突

自动每日北京时间20:00运行。手动15:00收盘后可尝试当天；此前只到前一已结束交易日，休市依独立交易日历取最近交易日，不猜工作日。

手动与自动从最后已有日期之后补到目标交易日，逐日执行；已持久记录的失败缺口独立保留，后续日期成功不使旧失败水位消失。首次无历史时日常任务只尝试最新日，2010起历史由聚宽入口恢复。首次失败跳过，整轮后最多再重试三轮；共同依赖拒绝等不可重试错误不会重复请求。进程锁、请求运行状态、取消与发布互斥，已有日期不覆盖。

存在聚宽目标日时，公开源可作重叠对照，保存逐成员差异、最大PE差异、均值与指数差异。自动避免重复已完成对照，手动可复核修订；有差异只记录，原聚宽值不改。对照失败不等于已有日缺数据，也不把一次成功对照扩展为所有历史口径等价。

## 存储与接口

数据位于 `LOG_DIR/market-data/valuation-ruler/`，包含SQLite结果、带符号成员、来源证据、比较和失败状态。不要提交这些生产文件。新环境迁移应使用已配置的聚宽MySQL历史导入，不清空原库。

`GET /api/v1/valuation-ruler/history` 与 `/status` 需要登录；`POST /refresh`、`/sync-joinquant`、`/cancel` 需要管理员和CSRF校验。202仅表示请求被接收，须检查状态、目标日期与缺口，不能当作数据已成功发布。`VALUATION_RULER_WORKER_ENABLED=false` 关闭自动任务，保留手动入口。

离线测试覆盖源契约、日期/数字/300成员校验、事务回滚、并发、取消、恢复、导入冲突、分位与前端状态。真实聚宽账号、MySQL生产环境及20点成分就绪仍须实测；当前云浏览器因socket权限错误未执行到交互断言。
