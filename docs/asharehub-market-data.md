# 市场热度与抱团拥挤度：AShareHub 原始日行情

## 替换范围

配置后，两项指标共用 AShareHub `GET https://asharehub.com/v2/market/daily?trade_date=YYYYMMDD` 的单交易日响应，替换原 TDX 日行情包中的以下输入：

- `close`：未复权收盘价，元。
- `vol`：手，乘以100换为股。
- `amount`：千元，乘以1000换为元。

每个交易日只请求一次全市场数据并保存经过校验的精简行情缓存。市场热度和抱团拥挤度共享同一输入；20日窗口复用缓存。请求只发送到固定 HTTPS 域名，密钥只置于 `X-API-Key` 请求头，不进入 URL。重定向不跟随，鉴权失败和限流立即停止本轮，不换接口绕行。

**没有替换的口径和安全核验：**

1. 股票池仍来自东方财富逐日报告，并用目标日真实成交、明确全天停牌记录和交易所逐板块数量交叉核验。不会把接口返回行数当股票池，也不会因缺行情删除个股。北交所数据不会扩大原沪深股票/CDR范围。
2. 热度仍使用原20个市场交易日、全精度新浪前复权因子和合格证券分母；保留停牌向前填充、新股不足20日排除和严格比较规则。**不使用接口提供的 `ma_qfq_20`、`close_qfq` 或 `adj_factor` 代替原计算。**
3. 拥挤度仍以完整日期股票池 N 为基数，取成交额前 floor(N×5%) 只证券；已确认停牌证券保留在 N 中。
4. 交易日历、复权因子、历史股票池、停牌、交易所分类数据及聚宽历史恢复脚本不变。沪深300月度权重不能代替逐日生效成分，本次未接入。
5. 只有全部独立核验通过才发布；空响应、混合日期、重复代码、无效数值或未解释的缺失均阻止相应结果。单日请求避免长区间接口截断，但并不把单日返回视为自动完整。

先前AShareHub Pro成交额存在源端舍入（新daily对照见文末）。2026-11-06审计样本中，5218只交易证券的原始收盘价与独立行情一致；单股成交额最大差5元。完整股票池为5224只（含6只已证实停牌），前261只相同，拥挤度均显示43.47%，但数据库10位小数比值不完全一致。这是数据源精度差异，不宣称逐位等价。

## 启用与回退

代码发布不会保存或自动配置之前用于测试的凭据。服务器管理员在受保护的服务环境变量中配置 `ASHAREHUB_API_KEY`，然后按既有方式重启 API。应用既有服务端配置文件也支持此字段，但不要把真实密钥提交到仓库、聊天或日志。示例文件仅保留空值。

- 未设置或为空：继续原 TDX 输入，旧配置正常工作。
- 非空：后续未完成采集选择 AShareHub；没有运行时失败后偷偷切回 TDX 的逻辑。
- 删除此配置并重启：后续未完成采集重新选择 TDX。
- `/api/v1/market-collection/status` 的 `raw_price_source` 返回当前配置选择的 `asharehub_daily` 或 `tdx_daily_archive`。它不是某条历史结果实际来源或实时可用性的证明，不返回密钥。

精简行情缓存在 `LOG_DIR/market-data/market-collection/source-cache/asharehub-raw-daily-v2`，不包含密钥、响应头或衍生技术因子。日期核验缓存与 TDX 使用不同目录；未完成任务的旧源快照需要重建，但已发布结果与原审计记录保留，不自动回写覆盖历史。

接口响应上限64MiB、精简缓存单文件上限8MiB；格式校验之外仍依赖原全市场完整性审计。首次无缓存的20日窗口可能需要20次请求，请根据账户实际额度安排历史补采。账户额度、生产密钥配置和实时服务可用性须另行确认。

## 上市日期核验与单证券故障

市场热度仍使用目标日前20个市场交易日。若证券只出现在窗口后段，必须取得明确上市日期且与首次出现交易日一致，才能按新股不足20日排除。改代码、漏行情、停牌不构成新股证据。

配置 AShareHub 密钥后，上市日期优先使用 `/v2/reference/stocks?list_status=L` 批量目录，同一北京时间日期共享内存/磁盘缓存；仅目标证券缺失时加载 D 目录。只使用明确的 `list_date`，不声称目录能重建全部历史成员。目录查无该证券或临时网络失败时使用东方财富 `stock/get` 的 f189 作为后备。身份/格式冲突、鉴权失败及限流不切源。批量目录临时连接失败后冷却60秒，避免每股重复拉全目录。

上市日期请求连接、读写、连接池阶段超时均为60秒，并有60秒协作式单次请求时间预算；正在等待的系统网络调用由阶段超时约束，因此不是硬墙钟60秒中断。临时连接失败最多额外重试一次（东财也重试临时读取失败）；东财还保留本轮累计180秒活动预算及32次请求上限。AShareHub加载L、D分别受单请求预算约束。

单只证券上市日期不可核验时记为待补，继续处理其他证券；全部必需观测齐全前不发布热度，绝不通过丢弃失败证券缩小分母。拥挤度已验证并写入的结果保留。日志记录来源、证券代码、目标日、窗口首次出现日期和请求尝试次数，不记录密钥或响应原文。
