# 微盘温度计：采集与展示

> 默认启用本地缓存：采集入库后，等待每天北京时间 07:00 自动同步，或在网页“数据同步”/服务器命令中手动同步。页面刷新读取当前快照，详见[本地缓存说明](local-cache.md)。


保留原程序的起始日期 **2021-01-01**、微盘股票数 **1000**，改为 **每个交易日采集一次**，结束日期在每次运行时取北京时间当天。独立采集文件负责写入 MySQL，showAllOpts 增加微盘温度计模块，网页只读数据。

## 聚宽运行

仓库模板：[微盘温度计_数据库版.py](../collectors/微盘温度计_数据库版.py)。

```python

END_DATE = None
MICRO_NUM = 1000

```

`END_DATE=None` 表示每次调用时取北京时间当天；实际运行区间会显示在控制台。将文件上传至聚宽研究环境后执行：

```python

```

也可直接粘贴整个程序运行。建议收盘且行情、估值数据就绪后执行；北京时间 16:00 前不写当天日值，已有日期不重复采集。首次回填需要获取多年估值、换手率和行情，可能受聚宽额度和网络限制；中途失败会停止，已成功的期数保留，修复后再次运行即可续算。不要同时运行同一序列的多个采集实例。

## 每日采集、历史补缺与旧数据迁移

默认从 **2021-01-01** 起按完整交易日历检查缺口，不只检查最新入库日。首次升级会补齐之前五日采样之间缺失的日期；周末和节假日不补。已有日频日期不重复采集，没有缺口及待修复记录时直接跳过行情和写入。

- 日频序列为 `micro1000_1d_20210101_v1`。原五日序列 `micro1000_5d_20210101_v1` 保留，用于迁移和展示回退。
- 原五日采样日的市值、拥挤度、PE、PB、利润增长和成分股直接复用，不再次请求整套原始指标；缺失日期才完整采集。指数衔接仍需查询相邻日期的端点价格。
- 日频序列需要重新计算历史分位、综合温度和每日等权指数，不能直接混用旧五日指数。近 5 日平均换手率仍采用 5 日窗口，改变的是采集频率。
- 日频回填尚未追上旧数据时，网页继续展示旧曲线并标注旧版采样间隔；追平或超过旧版最新日后自动切换，曲线不会混合两种序列。
- 默认参数不变时，后续每天仅采集新交易日；历史如有缺口则补采，并用已有原始指标重算缺口之后受影响的派生值。

每次只读取日期、样本计数和四列分位基准，准备处理的日期才读取完整快照与成分股。每个日期单独提交；插入缺口或修复派生值时，同一事务将下一条已有记录标为待衔接（`sample_count=0`）。中断后，即使缺失日期已经写入，也会继续完成后续修复。网页不展示待衔接点之后的未修复片段；缓存元数据同时比较更新时间和样本计数，识别同秒内的修复状态变化。

**完整保留历史，不执行 180 个交易日清理。** 默认只补采缺失原始数据，不主动回查已存原始指标的源修订。首次从五日转日频需要补采多年缺口，可能耗时较长；已提交日期会保留，中断后再次执行即可。

独立脚本和批量脚本均默认 `sample_step=1`，两处都已更新。自定义起始日期或微盘数量会形成另一序列，网页默认读取 2021 年起的微盘 1000 序列。

## 选股与原始指标

每个采样日获取当时的股票列表：

- 排除代码以 4、8、920 开头的股票；后者补齐原程序未覆盖的北交所新代码。参见 [北交所 920 号段公告](https://www.bse.cn/important_news/200021629.html)。
- 排除上市不足 **250 个自然日**的股票。
- 按采样日 ST 标记剔除 ST 股票。
- 获取当日市值、换手率、PE、PB；获取近 5 个交易日换手率及当日成交额。沿用原程序的数据清洗口径：估值、当日换手率、成交额须有效，过去换手率须有观测值；缺失观测不补零，近 5 日均值使用可用观测。整日接口缺失、重复股票、日期越界等异常停止采集。
- 按市值升序选取最小的 1000 只；市值相同时按代码排序，使重复运行稳定。零成交额有效，负 PE/PB 不剔除。有效股票不足 1000、换手率或成交额分母为零时停止。
- 从已筛选、数据完整的股票构成对照组。原程序的「全A」统计实际基于这个清洗后的集合，网页明确显示为「对照组」。

| 指标 | 计算方式 |
| --- | --- |
| 微盘市值中位数 | 微盘 1000 市值的中位数，亿元 |
| 对照组市值中位数 | 清洗后的对照组市值中位数，亿元 |
| 相对估值 | 微盘市值中位数 / 对照组市值中位数 |
| 换手率拥挤度 | 微盘股票近 5 日平均换手率的均值 / 对照组相同指标均值 |
| 成交额拥挤度 | 微盘当日成交额合计 / 对照组当日成交额合计 |
| PE / PB | 微盘 1000 中位数，允许为负 |
| 归母净利润增速 | 当时已公布报告的归母净利润同比增速中位数，单位 %；同时记录有效样本数 |

使用 `get_all_securities` 返回的上市日期，省去原程序逐只调用 `get_security_info` 的开销。财务与行情按批获取；行情统一用 `panel=False`，不依赖旧版 pandas Panel。相关接口参考 [聚宽股票数据文档](https://www.mytest.demo.joinquant.com/help/data/stock) 和 [聚宽 API 文档](https://cdn.joinquant.com/help/img/JoinQuantAPI.pdf)。

## 历史分位与综合温度

对每个采样点，使用从起点至当期（含）的样本排名，等价于原程序 `rank(pct=True, method='average')`，并列值取平均排名。分位存储为 0～1。

综合温度 = 相对估值分位 × 50% + 换手率拥挤度分位 × 25% + 成交额拥挤度分位 × 25%。

市值分位单独展示，**不参与综合温度权重**。网页将温度乘以 100 显示为 0～100，将分位显示为百分比。首期只有一个样本，分位为 100%；早期样本少时参考意义有限。切换近一月、一年等图表区间不会重新计算分位。

归母净利润增速原始字段本身已是百分数，网页不会再乘以 100。缺失值入库为 NULL，曲线保留断点。

## 等权指数续算

首期指数为 1000。相邻采样期收益使用**上期的全部 1000 只成分股**，逐只计算前复权价格收益，再取等权平均：

```text
本期指数 = 上期指数 × (1 + 上期 1000 只成分股的平均区间收益)
```

数据库在每期快照保存成分股列表，重启后读取上期成分股，不能用当期名单替代。两端收盘价在同一次 `get_price` 区间查询中取得，保持复权口径一致；调出股票也完整包含。任一上期成分股缺失有效端点价格会停止并提示股票代码，不像原程序那样静默剔除后对剩余股票重新分配权重。如果遇到退市等特殊情况，应先明确该股票的估值处理，不自动假设零收益。

这是程序编制的理论等权指数，不是官方指数，不包含交易成本和可成交性限制。

## 数据表与权限

表名：`microcap_temperature`，复合主键：`(series_id, trade_date)`。

| 字段组 | 字段 |
| --- | --- |
| 序列、采样信息 | series_id、trade_date、micro_num、sample_step、sample_count |
| 有效样本 | universe_count、profit_growth_count |
| 原始指标 | micro_median、all_median、relative_ratio、crowding_ratio、amount_crowding_ratio、pe_median、pb_median、avg_np_growth |
| 分位及温度 | cap_pct、relative_pct、crowding_pct、amount_crowding_pct、score |
| 指数与成分股 | micro_index、period_return、member_codes（JSON 文本） |
| 更新时点 | updated_at（北京时间） |

采集账号需有 SELECT、INSERT、DELETE 及首次 CREATE 权限。网页只读账号需有新表 SELECT 权限，网页不建表或执行迁移。复合主键已覆盖本模块的查询条件，不必重复添加同列索引。

网页查询默认不读取成分股 JSON，避免每期多传输 1000 只股票代码；一条 SELECT 读取指标，服务层裁剪显示范围与计算区间统计，不改变已经入库的分位和指数。

## 网页与 API

首页和导航入口：`/microcap-temperature`。

- 最新综合温度、指数、市值及换手率拥挤度；四类分位和权重分解。
- 主图可切换综合温度、市值分位、相对估值分位、换手率拥挤度分位、成交额拥挤度分位，并可叠加右轴等权指数。
- PE/PB 双轴图与归母净利润同比增速图。
- 30 / 90 / 180 / 365 个自然日及全部历史，默认一年，终点为最新入库采样日；滑块支持缩放。按实际交易日展示，不对缺失日期填零。

接口：`GET /api/v1/microcap-temperature/history?days=365`。days=0 返回全部；可传历史 end_date，不允许未来日期。空表返回 200 空结果；未建表、数据库连接或权限异常返回 503；非法参数返回 422。响应不返回成员名单或连接信息。
