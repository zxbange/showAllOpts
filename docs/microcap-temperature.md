# 微盘温度计：采集与展示

本模块已切换为聚宽原始采集、项目同步时本地计算，结果保存到本地SQLite供网页查询。独立及批量文件名不变，顶部使用 `DB_CONFIG` 和按策略分组的 `STRATEGY_CONFIG`。运行、首次迁移、原始表、增量和保留规则以[原始采集与本地计算](raw-pipeline.md)为准；下文说明计算口径。

## 选股与原始指标

每个采样日获取当时的股票列表：

- 排除代码以 4、8、920 开头的股票；后者补齐原程序未覆盖的北交所新代码。参见 [北交所 920 号段公告](https://www.bse.cn/important_news/200021629.html)。
- 排除上市不足 **250 个自然日**的股票。
- 按采样日 ST 标记剔除 ST 股票。
- 获取当日市值、换手率、PE、PB；获取近 5 个交易日换手率及当日成交额。沿用原程序的数据清洗口径：估值、当日换手率、成交额须有效，过去换手率须有观测值；缺失观测不补零，近 5 日均值使用可用观测。整日接口缺失、重复股票、日期越界等异常停止采集。
- 按市值升序选取最小的 1000 只；市值相同时按代码排序，使重复运行稳定。零成交额有效，负 PE/PB 不剔除。有效股票不足 1000、换手率或成交额分母为零时停止。
- 从已筛选、数据完整的股票构成对照组。原程序的「全A」统计实际基于这个清洗后的集合，网页明确显示为「对照组」。

| 指标 | 计算方式 |
| --- | --- |
| 微盘市值中位数 | 微盘 1000 市值的中位数，亿元 |
| 对照组市值中位数 | 清洗后的对照组市值中位数，亿元 |
| 相对估值 | 微盘市值中位数 / 对照组市值中位数 |
| 换手率拥挤度 | 微盘股票近 5 日平均换手率的均值 / 对照组相同指标均值 |
| 成交额拥挤度 | 微盘当日成交额合计 / 对照组当日成交额合计 |
| PE / PB | 微盘 1000 中位数，允许为负 |
| 归母净利润增速 | 当时已公布报告的归母净利润同比增速中位数，单位 %；同时记录有效样本数 |

使用 `get_all_securities` 返回的上市日期，省去原程序逐只调用 `get_security_info` 的开销。财务与行情按批获取；行情统一用 `panel=False`，不依赖旧版 pandas Panel。相关接口参考 [聚宽股票数据文档](https://www.mytest.demo.joinquant.com/help/data/stock) 和 [聚宽 API 文档](https://cdn.joinquant.com/help/img/JoinQuantAPI.pdf)。

## 历史分位与综合温度

对每个采样点，使用从起点至当期（含）的样本排名，等价于原程序 `rank(pct=True, method='average')`，并列值取平均排名。分位存储为 0～1。

综合温度 = 相对估值分位 × 50% + 换手率拥挤度分位 × 25% + 成交额拥挤度分位 × 25%。

市值分位单独展示，**不参与综合温度权重**。网页将温度乘以 100 显示为 0～100，将分位显示为百分比。首期只有一个样本，分位为 100%；早期样本少时参考意义有限。切换近一月、一年等图表区间不会重新计算分位。

归母净利润增速原始字段本身已是百分数，网页不会再乘以 100。缺失值入库为 NULL，曲线保留断点。

## 等权指数续算

首期指数为 1000。相邻采样期收益使用**上期的全部 1000 只成分股**，逐只计算前复权价格收益，再取等权平均：

```text
本期指数 = 上期指数 × (1 + 上期 1000 只成分股的平均区间收益)
```

数据库在每期快照保存成分股列表，重启后读取上期成分股，不能用当期名单替代。两端收盘价在同一次 `get_price` 区间查询中取得，保持复权口径一致；调出股票也完整包含。任一上期成分股缺失有效端点价格会停止并提示股票代码，不像原程序那样静默剔除后对剩余股票重新分配权重。如果遇到退市等特殊情况，应先明确该股票的估值处理，不自动假设零收益。

这是程序编制的理论等权指数，不是官方指数，不包含交易成本和可成交性限制。

## 网页与 API

首页和导航入口：`/microcap-temperature`。

- 最新综合温度、指数、市值及换手率拥挤度；四类分位和权重分解。
- 主图可切换综合温度、市值分位、相对估值分位、换手率拥挤度分位、成交额拥挤度分位，并可叠加右轴等权指数。
- PE/PB 双轴图与归母净利润同比增速图。
- 30 / 90 / 180 / 365 个自然日及全部历史，默认一年，终点为最新入库采样日；滑块支持缩放。采样点之间没有为每日填值或补零。

接口：`GET /api/v1/microcap-temperature/history?days=365`。days=0 返回全部；可传历史 end_date，不允许未来日期。空表返回 200 空结果；未建表、数据库连接或权限异常返回 503；非法参数返回 422。响应不返回成员名单或连接信息。
