## 数据链路与部署状态

交易所公开接口 → 独立采集器 → MySQL `etf_share_daily`、`etf_price_daily` 与 `etf_trading_day` → 服务器只读同步 → 本地快照 → API与图表。新流程不依赖聚宽，不回退到第三方行情。历史聚宽份额保留，不删除原表或历史记录。

采集器为 [etf_exchange_collector.py](../collectors/etf_exchange_collector.py)，配置、命令、数据源及退出码见[运行说明](etf-exchange-collector.md)。默认仅探测，`--write` 才入库。旧 `ETF份额_数据库版.py` 保留用于兼容历史流程，不用于新流程；聚宽批量采集已移除旧ETF份额工厂、参数和注册项，避免混合源覆盖。

自动采集已接入FastAPI生命周期，功能默认启用；显式设置 `ETF_COLLECTION_ENABLED=false` 可关闭。推荐在页面配置主机、端口、库名及账号密码，可用已有且具备权限的账号；自定义目标只影响ETF，采集写入和图表/缓存读取使用相同配置，其他模块不变。切换目标后旧ETF缓存不可作为新库数据展示，须重新同步。旧 `ETF_COLLECTION_WRITER_URL` 仍要求与应用数据库目标一致。缺配置、目标不符、写入权限不足时页面和状态API明确报未就绪/失败，不静默复用未配置的凭据、不创建账户或改权限。连接账号需三张表SELECT、INSERT、UPDATE，首次缺表时需CREATE权限。开发与只读验证阶段没有连接生产数据库或实际启用服务器采集；生产发布结果以对应GitHub Actions部署与健康检查为准，发布不代替写入账号配置。网页刷新不触发交易所采集，只读取已发布快照。

计划为北京时间09:30和11:30复核最新已闭市日份额，18:30采份额和价格；每槽最多2次、相隔30分钟，周末仍可复核和分批补历史。07:00原同步不变，采集写入后仅发布ETF快照。多进程共享持久目录和文件锁去重，不是跨主机分布式锁。默认历史目标300交易日，每轮最多5个历史日加最新日，逐只、逐日、逐数据类型记录缺口；这不代表首次已补齐300天。单缺口最多6次，超过后显式待排查，深市未验证旧价格标为blocked不无限请求。详见[后台采集设计](etf-collection.md)。

## 计算与缺失处理

- 每个日期、每只基金严格按代码与日期匹配：`市值（元）= 当日份额（份）× 当日收盘价（元/份）`；当前指数组将成员市值相加。这里“加权”按用户示例理解为各基金市值之和，不再额外乘权重，也不把不同ETF的份额直接相加当资产规模。
- 只展示该组跟踪名单的合计，不是指数全部成分股市值，也不是基金净资产/净值。市值不是资金净流入。
- 任何成员缺同日份额或有效价格时，该日合计为null。禁止以最新价代替历史价、净值代替价格、缺失填0、向前填充或将部分成员求和当完整合计。源明确发布的0份额可以参与计算。
- 市值内部用Decimal精确计算，以十进制字符串返回元金额；图表换算亿元并正常舍入。份额沿用BIGINT字符串，单位份，图表为亿份。
- 总份额曲线下方展示近5个交易日份额列表，每行一只ETF，按本组统一日期显示T-4、T-3、T-2、T-1、T日及实际日期，单位亿份；最后一列为T日减T-1日的份额增减，不显示变动比例。任一比较日缺失则增减留空，不前向填充或跨缺口比较。点击ETF名称可聚焦曲线，再次点击恢复全部；市值模式没有单只基金选择或单只市值。缺价格时份额仍可查看，市值页提示数据未齐。
- 采集区保留“立即采集”、取消、配置及采集记录，移除常驻的自动采集说明、手动采集状态文字和重复操作说明；运行进度及本次操作错误仍正常显示。
- 默认近365自然日，可选30/90/180/365日或全部；范围终点取本组最新份额记录。横轴缺点不插值，数据日期不等于今天或实时行情。

## 官方接口验证及明确边界

2026-11-07实际只读验证了全部18只最新2026-11-06份额与收盘价。两所份额单位均为万份，入库前精确乘10000。深交所明确T日晚份额为参考值、T+1早间更新为准，因此后台每日复核最新已收市日并接受同日修订，另按缺口渐进补历史；独立CLI默认查询最近5个交易日。

上交所日价接口可返回历史。510180跨2009一拆十、2013四并一事件的日价仍保留相应跳变，抽样支持未复权特征，参考[华安2009拆分公告](https://wap.huaan.com.cn/news/2009-05-18/137247_1.shtml)和[2013合并公告](https://www.huaan.com.cn/news/2013-12-12/176880_1.shtml)。这不是所有品种全部历史口径的保证。

深交所日K当前实测仅返回最近201个交易日，额外日期/count参数不扩展历史。历史复权规则没有完整官方说明。**当前保守实现只保存与深交所同日15点以后成交行情now交叉一致的收盘价**；不能宣称深市历史市值已回填。包含深市成员的组在更早缺价日期保持空白，后续每日积累。`getTimeData.data.close`是昨收，不当成当日收盘。

份额拆分、合并日可能存在“日终份额已调整、当日收盘价尚未调整”的时点差异。当前保守检测：相对真实前一交易日，份额比值≥1.5或≤2/3，或收盘价比值≥1.25或≤0.8，视为疑似份额单位变化/异常跳变；份额异常日及下一已知交易日、价格异常日及前一交易日不输出该组总市值。风险计算额外读取窗口前后相邻记录及其真实前日，最后裁剪至所选区间，避免换时间范围使同一天风险结论改变；已知后一天价格变化可回溯屏蔽历史终点。不把缺口前最后记录冒充前日。原始份额保留，不猜拆分比例、不自动修正金额。页面提示待核验，API提供quality_flags/excluded_funds。真实大额申赎也可能被保守屏蔽；此规则不是完整基金事件库，较小单位变化或缺比较基数仍需进一步事件证据，不能保证识别全部拆并。

已改动态官方交易日历：上证指数完整已发生日期，加深交所当前/前月逐日开休市标志和当天nowdate交叉验证，跨年无需添加固定年份。日历未发布、陈旧、截断或与行情不一致时明确失败，不猜休市。已实测2025-12-31至2026-01-05跨年，前交易日正确；历史日历当前从1990-12-19开始。日历范围不代表所有ETF份额/价格从该日起都有数据。

## API与缓存兼容

`GET /api/v1/etf-shares/history?group=hs300&days=365`。支持上述7个group、历史end_date，不允许未来日期。保留原funds、份额、增减、旧change_pct字段，新增：

- `group_options`: 指数组id/name。
- `market_values`: `{date, market_value, available_funds, expected_funds, excluded_funds, quality_flags}`；金额为元字符串，未完整或疑似拆并时为null。
- `GET /api/v1/etf-shares/collection-status`：受登录保护的只读调度状态，显示未就绪原因、计划、实际运行、覆盖目标和缺口，不含写入凭据。

新增价格表独立于旧份额表，不修改旧份额列。旧库尚无价格表时返回份额与缺价提示，不将缺价视为0。数据库权限、连接和查询错误仍明确报503。

ETF缓存改为份额、价格和已发生交易日三张表的值/元数据对账，接受历史补采、同日修订、晚到价格；时间戳同一秒也能识别数值变化。不再仅以最大日期判断无变化。只发布完整事务后的新SQLite快照，失败保留旧快照。其他模块的缓存目录标识及追加策略不变。新表缺失时份额可以同步，不能因此清空其他模块数据。
