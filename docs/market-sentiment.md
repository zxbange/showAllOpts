# 市场情绪跟踪

页面入口为“市场情绪”，下设“抱团拥挤度”“市场情绪跟踪”和“两融担保比例”三张切换卡片。原 `/market-crowding` 链接继续可用；MA20曲线位于 `/market-sentiment`。两融模块直接采集中证官方日报，使用独立的20点任务，见[两融担保比例](margin-guarantee.md)。

## 指标与股票范围

**站上 MA20 比例 = 当日收盘价严格高于 MA20 的有效股票数 ÷ 当日有效股票总数。**

- 按每个历史交易日的上市、退市日期还原股票池，包含 ST、科创板、创业板和北交所 A 股，不套用短线选股的 ST 或市值过滤。实际覆盖以聚宽返回的股票资料及行情为准；B 股不计入。
- MA20 为含当日的最近 20 个市场交易日前复权收盘价的算术平均。历史停牌日使用聚宽填充的前收盘价；当日停牌、新股不足 20 日或退市后均不计入分母。
- 严格低于 20% 为冰点，严格高于 80% 为过热；恰好 20% 和 80% 属于正常区间。收盘价等于均线不算站上。
- 上市期间缺失行情或停牌状态时，当前窗口报错而不是静默缩小分母；行情不足 20 日的新股是正常排除。平台尚未收录的市场不能凭空补入。
- 北京时间 16:00 前不采集当天日值；建议在收盘行情就绪后运行。

股票资料使用 `get_all_securities(types=['stock'], date=None)` 获取所有日期的证券，随后按历史上市、退市日期筛选。接口语义见 [聚宽官方 API 文档](https://cdn.joinquant.com/help/img/JoinQuantAPI.pdf) 和 [官方 SDK](https://github.com/JoinQuant/jqdatasdk/blob/master/jqdatasdk/api.py)。

## 聚宽运行

独立脚本：[市场情绪跟踪_数据库版.py](../collectors/市场情绪跟踪_数据库版.py)。填写顶部 `DB_CONFIG` 后，将完整文件粘贴到聚宽研究环境，或上传后运行：

```python
%run -i 市场情绪跟踪_数据库版.py
```

也已加入 [策略批量采集_数据库版.py](../collectors/策略批量采集_数据库版.py)，默认排在抱团拥挤度之后。两个入口计算规则相同，都不依赖外部策略文件。顶部配置：

```python
STRATEGY_CONFIG['市场情绪跟踪'] = {
    'end_date': None,   # 运行当天；16:00 前排除当天
    'batch_size': 300,  # 每次行情请求的股票数
    'window_size': 40,  # 每个历史计算窗口的交易日数
}
```

首次自动创建 `market_sentiment` 表并回填最近三年。首次需要读取全市场历史行情，耗时受聚宽额度影响；控制台显示历史窗口、股票批次与耗时。后续查询已有日期，只采集缺失交易日，已入库日期不覆盖。没有缺口时，不再查询股票资料或行情。

- 历史回填按窗口计算和提交；默认一次行情请求最多 300 只股票、59 个交易日（40 日结果及 19 日预热）。每个窗口提交后可续传，中断重跑仅补未保存日期。
- 日常只有一个新增日期时，只请求该日及前 19 个交易日行情，不重算三年历史。
- 每次运行删除早于“北京时间运行日期减三年”的记录；边界日期保留。按自然年计算，闰年 2 月 29 日对应三年前的 2 月 28 日。
- 主键为交易日，入库前再次检查日期，避免重复写入。不要同时启动多个采集实例。
- 不保存逐股原始行情、均线或股票名单，只保存每日汇总；三年通常约七百多个记录。

## 数据与同步

| 字段 | 内容 |
| --- | --- |
| `trade_date` | 交易日期，主键 |
| `ratio` | 站上均线比例，DECIMAL(18,10)，范围 0～1 |
| `above_count` | 站上均线的股票数 |
| `eligible_count` | 剔除当日停牌及不足 20 日后的有效股票数 |
| `universe_count` | 当日已上市的 A 股数，含当日排除样本 |
| `updated_at` | 计算入库时间，北京时间 |

采集账号需 SELECT、INSERT、DELETE 及首次 CREATE 权限；项目源数据库账号只读新表。计算在聚宽完成，项目仅同步每日结果到本地 SQLite 快照并生成显示统计。

发布步骤：

1. 在聚宽运行新版独立或批量脚本，确认“市场情绪跟踪”成功。
2. Linux 更新项目并执行既有 `bash deploy.sh`；本地开发重启后端。
3. 页面“数据同步”选择“市场情绪跟踪”，完成后打开“市场情绪”下对应标签。

该模块沿用北京时间 20:00 自动同步、手动同步及逐模块停止功能。启动不自动同步。缓存按日期和更新时间增量下载，并同步删除源表过期记录；新模块不会使原有模块缓存或机构持仓续传点失效。

`GET /api/v1/market-sentiment/history?days=0` 默认显示近三年；`days` 支持 0、30、90、180、365，非零区间以最新已采集日期为终点。可传 `end_date` 查看历史截面，不接受未来日期。返回比例、每日样本数、最新值与区间统计；图表不为缺失日期填零。

## 验证范围

离线测试覆盖 MA20、相等边界、停牌、新上市、历史退市、数据缺失、首次回填、增量跳过、分窗口续传、三年清理、API 与缓存；浏览器检查覆盖桌面和移动端标签、图表、范围及错误恢复。聚宽真实接口权限与历史数据完整性仍需在研究环境首次运行确认。
