# 工程与页面规范

## 维护原则

先复用、再提取；删除重复实现，不引入第二套组件库、任务框架或配置中心。只有存在真实的共同职责才共享代码，数据口径不同的模块保留独立实现。

| 位置 | 单一职责 |
| --- | --- |
| `backend/app/api/routes` | 权限、参数与响应，不运行长任务 |
| `backend/app/services` | 业务计算、公开数据采集及服务调度 |
| `backend/app/repositories` | 本地快照查询 |
| `backend/app/core` | 连接、配置、快照、同步、日志 |
| `frontend/src/pages` | 页面编排及页面状态 |
| `frontend/src/components` | 已被复用的界面组件 |
| `frontend/src/hooks` | 请求取消、轮询生命周期 |
| `frontend/src/styles` | 共用设计变量和必要的模块样式 |
| `collectors/` | 可直接在聚宽运行的采集入口 |
| `collectors/rules`、`collectors/tools` | 公共规则维护源及本地嵌入工具 |
| `scripts/`、`deploy/` | 运维命令与部署模板 |

聚宽运行时仅共用 `mysql_connector.py`，不导入其他策略或后端。不要为减少入口行数改成运行时拼接、动态下载或加载隐藏脚本。

## 页面标准

参考 [Apple 的布局指南](https://developer.apple.com/design/human-interface-guidelines/layout)：清晰层级、关联内容对齐、详情按需展开，适配桌面与手机。数据工作台保留紧凑表格，不复制营销页面的大留白或品牌外观。

- 页面统一 `PageHeader`：标题和常用操作在上，`ModuleSwitch` 在下，再进入筛选、指标和图表/列表。加载与失败也保留标题、导航。
- 全站使用 `global.css` 的颜色、圆角变量；图表用 `chartTheme.ts`。内容字号以 14–15px 为主，辅助信息不低于 13px。小标签可用 12px，主标题 28px。
- 中性背景、白色内容面板；强调色用于当前选中和主要操作。涨跌继续用市场约定的红绿，不能只靠颜色表达状态。
- 每块只保留必要标题、指标单位和一句核心口径。长说明放原生 `details/summary`，不新建弹窗或状态管理。
- 控件优先原生元素，主要点击区域至少 44px；保留键盘焦点、左右切换、屏幕阅读器标签、减少动态效果设置。
- 小屏允许表格和模块标签局部横滚，整页不得横向溢出。不用缩小字体解决空间不足。
- 刷新读取本地数据；同步更新缓存；采集获取源数据。按钮名称与实际动作一致，不混用。
- 空值显示 `—`，不补零；金额、股数、百分比标清单位；技术错误保留可操作的短提示，详细诊断写日志。

## 采集与同步

复用已有连接配置和增量协议，不增加并行层。连接由使用它的最外层上下文关闭；不能在持有唯一连接时嵌套调用另一个需要连接的任务。

采集器计算完成后提交结果；重复运行不重复写未变化数据。结果与变更记录在同一事务提交。无新增时仍须初始化同步协议，避免网页回退全量对账。

同步读源库使用一致性快照，按主键分页；本地写入临时文件，校验成功才发布。无变化复用已发布文件，失败、取消保留上一份成功数据。不要把“最大日期相同”用于判定所有模块无变化：历史修订、同日迟到数据、删除和披露更新都可能发生。

具体策略只维护在[同步策略](../operations/cache-sync-strategies.md)，脚本入口只维护在[采集目录](../../collectors/README.md)。

## 验证与变更

- 复用 `backend/.venv` 和现有 Node 依赖，不为每次修改创建环境。
- 后端验证事务、重复运行、增量范围、取消和失败回滚；前端验证桌面与手机的导航、筛选、加载和异常。测试使用隔离数据。
- 公共规则的嵌入检查必须通过；不能只修改独立脚本遗漏批量版。
- 文档按 `data`（模块口径）、`operations`（运行排错）、`development`（工程规范）归类；移动时更新所有相对链接。
- 不改用户私有配置，不删除历史表、运行数据或密钥。提交只包含本次整理，并跟踪 CI 与部署实际状态。

## 本次检查结论

已整理所有现有页面入口和样式，合并管理页面的页头，删除总览装饰图与重复说明；文档从平铺目录归类，README 收敛为启动入口。ETF 同步复用已读入的窗口数据，避免变化记录二次查询。

保留各模块既有同步协议与历史修复入口。没有把全项目改成只看最大日期，也没有新增任务框架。自动测试可验证逻辑，不能代替聚宽真实权限、生产数据库网络速度和上游数据完整性验证。
