# 前端共用框架候选（阶段 5）

此文为后续重构边界，不是已发布功能。先完成采集生命周期迁移及各策略回归，再按页面的真实共性提取界面组件；不调整业务数据口径、路由或采集权限。

| 候选 | 已有基础及试点 | 必须保留 |
| --- | --- | --- |
| 模块页头和操作工具条 | `PageHeader`、`ModuleSwitch`、`PageHeaderActions` 已存在；归一化按钮外观及状态映射时先比较两融/创红比/估值、高股息/奶牛股、大宗商品。 | 右侧操作区不随标签滚动；估值/高股息/A00/CCI 不新增取消；两融/创红比/奶牛股的取消权限保留；数据库同步和公开采集仍不同。 |
| 采集进度和错误区 | 共享任务状态生命周期，不共享业务进度字段；以现有进度组件和 `CollectionHistory`、`CollectionOutcome` 为基础。 | 区分尚未确认、任务终止、失败、待发布与实际数据更新时间；不虚构百分比、错误或成功。 |
| 图表外框 | `chartTheme.ts`、各模块 `*Chart.tsx` 重复初始化、ResizeObserver、销毁、日期范围控制。先提取图表生命周期和外框，后迁移每个业务 option。 | 不改变指标单位、图表轴、空值、日期筛选、工具提示；A00/CCI 禁止滚轮缩放，滑条/其他交互保留。 |
| 分区和指标卡 | `StatCard` 已复用；比较市场情绪、估值、两融、商品的摘要卡及趋势区域。 | 收盘价、价格、股息率、金额单位及无值提示不同；不引入统一四舍五入或业务计算。 |
| 结果列表与筛选 | 高股息、奶牛股、机构持仓、ETF 已有表格、筛选和历史详情。先抽取无业务逻辑的表格外框、空状态、搜索与筛选控件。 | 保留各列、排序、证券编码、年限/银行分类和历史弹层；不共用不一致的数据契约。 |

阶段 2 的架构边界：共享 `useCollectionTask` 管理任务与鉴权会话作用域、状态请求生命周期、重复命令防护。HTTP 端点及业务确认规则由各模块适配器定义；大宗商品保留合并的历史/状态读取和非活跃时停轮询，奶牛股保留按年限的视图读取但共用全局任务锁。市场热度/拥挤度、ETF 与持仓的队列、请求幂等和缓存发布有自己的契约，适配前先核对，不能仅因为按钮相同就移除其原有防护。

每次只迁移一组页面，检查页面只读权限、窄屏溢出、标签切换、日期/筛选、取消、陈旧响应和错误后旧数据可见性。通过质量门禁、单测、构建和桌面/手机 E2E 后才合并；无需求的视觉变化另行评审。

阶段 2d：市场热度/拥挤度和 ETF 采用同一个 `useQueuedCollectionTask` 队列生命周期，按会话和任务身份共享命令及重试状态，仅在页面挂载时读取状态，卸载不取消已经提交的任务。市场的 busy 冲突、幂等 UUID 与缓存发布规则、ETF 的耗尽重试选择、手动任务 ID 和取消回执由各自适配器维护。普通采集的布尔启动确认不套用于这些有队列/幂等回执的接口。

个人持仓暂保留独立实现（`PersonalHoldingsPage.tsx` 的状态读取、持仓版本复用、估值变化、历史分日分页和监控启停/手动同步）。后续先抽取无业务语义的请求世代与命令锁，确保持仓版本不变而收盘价变化仍能更新，不把监控启停或历史加载误当成队列采集。不要为了统一而将其强制映射到 ETF 或市场任务状态机。

阶段 5 第一轮候选：将已有页头操作统一到 `PageActionButton` / `DisplayRefreshButton`（原生 button、视觉等级、装饰图标、可访问名称和禁用条件），不更改现有动作名称及权限；历史预设统一到受控的 `HistoryRangeSwitch`，保留各模块原有天数/年数、空选中的自选区间与日期表单；相似趋势区共用 `TrendPanelHeading`，原有图表、数据来源链接、状态徽标和 CSS 布局保持。监控启停仍是独立操作，不与更新持仓混用。

后续小步候选（须单独回归，不属于本轮）：

1. 先收敛图表挂载、尺寸监听及清理，保留每个图表的 option、指示线、日期窗口、滚轮/滑块/触屏手势与可访问说明；验证图表工具链和缩放状态。
2. 评估趋势区数据承载（loading / error / empty / 保留旧图表）是否能共享外框。各模块的旧快照保留规则不同，不统一为清空策略。
3. 评估高股息、奶牛股、持仓及 ETF 表格的搜索、分页与横向滚动外框，保留业务列、格式、聚合范围和历史分红弹层。
4. 最后分离超大页面及局部 CSS。没有必要不增加 UI 库、不改变路由、不重写图表口径，也不将配置、监控、登录混入采集控制。

阶段 5b 候选：12 个 ECharts 使用点共用 `createChartInstance` 的初始化、观察、销毁与过期 resize 响应防护；其中 8 个原先只在挂载时创建的图表使用 `useEChart`，选项仍由各图表自行更新。创红比保留专用 datazoom 监听、标注刷新及解绑顺序；A00/CCI/机构持仓保留原先随数据变化重建实例的行为，未改变缩放、期数、图例、数据精度或图表参数。两融 E2E 在已有范围/刷新测试中额外检查实例 ID 不变。

已有七处可滚动表格（商品两页、奶牛股、高股息、ETF、持仓当前和历史）复用 `ScrollableTableRegion`；外层仍是原 CSS class 的原生 div、可键盘聚焦的具名 region，内部原生表格、caption、行列、按钮、筛选及分页不变。机构持仓的带 ref/aria-busy 的表格、微盘新高新低的非聚焦表格暂不强行合并，后续按实际可访问性和滚动需求单独审查。

剩余候选：统一可复用的趋势区加载/空状态外框、搜索与分页控件、逐步局部化模块 CSS。是否迁移独有图表重建策略、表格焦点恢复、特殊数据缺口展示应由实际回归决定，不在本轮修改。
