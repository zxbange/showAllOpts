# 前端共用框架候选（阶段 5）

此文为后续重构边界，不是已发布功能。先完成采集生命周期迁移及各策略回归，再按页面的真实共性提取界面组件；不调整业务数据口径、路由或采集权限。

| 候选 | 已有基础及试点 | 必须保留 |
| --- | --- | --- |
| 模块页头和操作工具条 | `PageHeader`、`ModuleSwitch`、`PageHeaderActions` 已存在；归一化按钮外观及状态映射时先比较两融/创红比/估值、高股息/奶牛股、大宗商品。 | 右侧操作区不随标签滚动；估值/高股息/A00/CCI 不新增取消；两融/创红比/奶牛股的取消权限保留；数据库同步和公开采集仍不同。 |
| 采集进度和错误区 | 共享任务状态生命周期，不共享业务进度字段；以现有进度组件和 `CollectionHistory`、`CollectionOutcome` 为基础。 | 区分尚未确认、任务终止、失败、待发布与实际数据更新时间；不虚构百分比、错误或成功。 |
| 图表外框 | `chartTheme.ts`、各模块 `*Chart.tsx` 重复初始化、ResizeObserver、销毁、日期范围控制。先提取图表生命周期和外框，后迁移每个业务 option。 | 不改变指标单位、图表轴、空值、日期筛选、工具提示；A00/CCI 禁止滚轮缩放，滑条/其他交互保留。 |
| 分区和指标卡 | `StatCard` 已复用；比较市场情绪、估值、两融、商品的摘要卡及趋势区域。 | 收盘价、价格、股息率、金额单位及无值提示不同；不引入统一四舍五入或业务计算。 |
| 结果列表与筛选 | 高股息、奶牛股、机构持仓、ETF 已有表格、筛选和历史详情。先抽取无业务逻辑的表格外框、空状态、搜索与筛选控件。 | 保留各列、排序、证券编码、年限/银行分类和历史弹层；不共用不一致的数据契约。 |

阶段 2 的架构边界：共享 `useCollectionTask` 管理任务与鉴权会话作用域、状态请求生命周期、重复命令防护。HTTP 端点及业务确认规则由各模块适配器定义；大宗商品保留合并的历史/状态读取和非活跃时停轮询，奶牛股保留按年限的视图读取但共用全局任务锁。市场热度/拥挤度、ETF 与持仓的队列、请求幂等和缓存发布有自己的契约，适配前先核对，不能仅因为按钮相同就移除其原有防护。

每次只迁移一组页面，检查页面只读权限、窄屏溢出、标签切换、日期/筛选、取消、陈旧响应和错误后旧数据可见性。通过质量门禁、单测、构建和桌面/手机 E2E 后才合并；无需求的视觉变化另行评审。
