# 两融平均维持担保比例

入口：“市场情绪 → 两融担保比例”，路径 `/margin-guarantee`。展示中证官方披露值、与上个已采集日的变化（百分点）、距240%参考线、近六年历史分位、最高最低值和日期，以及历史曲线。

## 来源与口径

只使用中证数据官网的[每日数据](https://www.csdata.cn/cmsmc/cgfb/rzrqsj/rzrqscmrsjtj/index.html)和[日度历史数据](https://www.csdata.cn/cmsmc/cgfb/rzrqsj/rzrqsclssj/rzrqscmrsjtj/index.html)，不调用聚宽，不从两融余额或担保物总价值反推这个平均比例。

以报表内的指标日期为准，目录发布日期可能晚一天。按Excel百分数格式或明确的百分号规范化单位：例如2026-10-26报表的原值2.556273保存为255.6273%。日期、字段、单位或值无法校验时不入库，不填零。

240%和150%仅作图表参考线，不代表当前统一适用的监管要求。历史分位为“有效样本中严格低于当前值的数量 / 有效样本总数 ×100%”，同值不计入低于数量。最高最低值并列时取最早日期。统计仅基于成功获取的官方样本，目录无披露的日期不造数，初次补采未完成时统计仍会变化。

## 自动更新与首次补采

- 后端运行时，每天北京时间20:00检查一次，调度约30秒内触发，不依赖服务器本地时区。当天未发布则保留最近已发布值，页面明确显示实际数据日期；不会把旧记录改成当天。
- 默认开启。`MARGIN_WORKER_ENABLED=false` 可关闭定时检查。与MySQL缓存同步独立，其他模块同步慢不会阻塞此任务。
- 启动仅注册定时任务，不立即下载，也不补跑停机错过的时段。首次可点击页面“更新数据”，或等待运行期间的下一个20:00。
- 首次读取近六年的官方目录，建立待补清单，优先采集最新日期，再向历史补齐。每成功校验一天就提交一次，页面可显示已保存数据。
- 后续只检查最新目录附近七天的新披露，并继续处理已有待补清单；已入库日期不重复下载。失败日期保留待补，下次重试。遇到连续三个报表失败则结束本轮，避免反复请求故障服务。
- 多个后端进程通过共享文件锁和持久任务日期避免重复采集。停止按钮仅在运行时出现；取消会等待正在执行的有超时限制的请求返回，再停止，保留已提交记录。

历史记录按运行当天向前六个自然年保留，每次成功读取披露目录后清理过期记录。首轮历史下载量较多，可分次完成；不影响已有页面的数据读取。

## 存储与部署

数据存放在 `LOG_DIR/market-data/margin-guarantee/history.sqlite3`：`points` 为每日有效比例，`reports` 为官方日报清单，`state` 为任务进度与调度记录。无需新增MySQL表或研究环境采集脚本。备份和迁移时保留整个目录，不要把它当临时日志清理。

更新代码后安装新版后端依赖（包含XLS/XLSX解析器）、构建前端并重启后端。常规项目部署流程会完成这些操作。服务须能通过HTTPS访问 `www.csdata.cn`，保持证书验证开启。

API：`GET /api/v1/margin-guarantee/history`、`GET /api/v1/margin-guarantee/status`、`POST /api/v1/margin-guarantee/refresh`、`POST /api/v1/margin-guarantee/cancel`。刷新返回202只表示后台请求已处理，最终结果以状态为准；已在采集时返回 `started:false`。
