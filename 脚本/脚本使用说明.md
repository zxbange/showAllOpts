# 本机采集与研究脚本

此目录存放本项目使用的采集入口和数据接口核对工具。`本地专用/` 被 Git 忽略，原数据库配置保留，换电脑时需要单独备份。

## 常用入口

| 任务 | 文件 |
| --- | --- |
| 日常批量采集 | [全部策略批量采集](本地专用/聚宽采集/全部策略批量采集_数据库版.py) |
| 单独采集个股机构持仓 | [个股机构持仓采集](本地专用/聚宽采集/个股机构持仓采集_数据库版.py) |
| 基金分类与规模去重研究 | [基金分类研究](../collectors/ETF分类去重_研究版.py) |
| 聚宽两融担保比例字段核对 | [两融字段核对](数据核对/聚宽两融担保比例字段核对.py) |

## 目录职责

```text
collectors/                 公开采集和研究模板，连接配置为占位值
scripts/                    网页启动、部署、数据库维护
backend/tests/              采集、计算、同步和接口测试
脚本/
├── 脚本使用说明.md
├── 数据核对/               聚宽等数据接口字段核对
└── 本地专用/               不提交 Git
    ├── 聚宽采集/           已配置连接的独立采集与批量采集入口
```

聚宽采集脚本保持完整单文件，核对顶部参数后，把完整代码粘贴到聚宽研究单元格运行。计算后的结果写入数据库，网页继续按原方式同步。
