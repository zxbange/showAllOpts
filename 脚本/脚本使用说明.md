# 本机采集与研究脚本

此目录只保留本项目使用的带配置采集脚本和短线胜率统计。`本地专用/` 被 Git 忽略，原数据库配置保留，换电脑时需要单独备份。

## 常用入口

| 任务 | 文件 |
| --- | --- |
| 日常批量采集 | [全部策略批量采集](本地专用/聚宽采集/全部策略批量采集_数据库版.py) |
| 单独采集个股机构持仓 | [个股机构持仓采集](本地专用/聚宽采集/个股机构持仓采集_数据库版.py) |
| 三个短线战法胜率研究 | [短线选股胜率](../collectors/短线选股胜率_研究版.py) |
| 基金分类与规模去重研究 | [基金分类研究](../collectors/ETF分类去重_研究版.py) |
| 超短线历史行情入库 | [历史行情采集](本地专用/聚宽采集/超短线历史行情采集_研究版.py) |
| 本地四策略胜率统计 | [四策略胜率统计](本地专用/本地统计/超短线四策略胜率统计_本地版.py) |

## 目录职责

```text
collectors/                 公开采集和研究模板，连接配置为占位值
scripts/                    网页启动、部署、数据库维护和公开本地统计工具
backend/tests/              采集、计算、同步和接口测试
脚本/
├── 脚本使用说明.md
└── 本地专用/               不提交 Git
    ├── 聚宽采集/           已配置连接的独立采集与批量采集入口
    └── 本地统计/           已配置连接的四策略胜率统计
```

聚宽采集脚本保持完整单文件，核对顶部参数后，把完整代码粘贴到聚宽研究单元格运行。计算后的结果写入数据库，网页继续按原方式同步。

本地统计脚本使用本地 Python 和原有依赖，只读查询历史行情数据库。研究输出、数据留存规则和数据库配置均沿用原设置。具体使用方法见 [超短线行情采集](../docs/ultra-short-collection.md) 和 [四策略胜率统计](../docs/ultra-short-statistics.md)。

公开模板与本地配置版需要同步业务修改。新增脚本使用清晰的中文功能名，文件头注明用途、运行环境、操作方法和读写范围；与本项目无关的交易策略、生成工具、独立通知和安装程序不再放入项目。
